# 부품일반정보·단가조회·품목별 현황

## 개요
부품 마스터 정보 조회, 단가 조회, 품목별 주문현황, 업체재고정보 등 부품/품목 중심의 조회 화면군을 개발했다. 부품 코드 검색과 상세 팝업(차종/적용차종)까지 포함한다.

- 부품일반정보 모듈(`PartsInfo`, `PartsTable`, `PartsPop`, `PartsSearchBar`, `PartsMobileView`, `PartsPagination`)을 구성하고 API(`api/axios/parts.ts`, `useSearchPartsInfo.ts`)와 타입을 정의했다.
