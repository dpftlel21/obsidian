# 로그인 인증과 세션 타이머 관리

## 개요
ERP 접근의 관문인 로그인/인증과, 장시간 미사용 시 자동 로그아웃을 위한 세션 타이머를 개발했다. 초기에는 하드코딩 로그인으로 시작해 API 연동, 단일책임원칙 기반 리팩토링, 세션 검사 로직으로 점진 발전시켰다.

## 주요 커밋
- `2025-03-26` `2e3ff71` 타이머에 따른 세션 초기화 구현 (SessionTimer, Toast 추가)
- `2025-04-11` `64411b7` 로그인 로직 리팩토링 (단일책임원칙)
- `2025-04-11` `b0b3647` 로그인시 리다이렉트 수정
- `2025-05-12` `a7d4437` 하드코딩 로그인 (DT00001, 1234)
- `2025-05-15` `557108f` session 로그인 검사 로직 추가
- `2025-11-20` `f8a203a` 로그인 개발 (차량 접수용 CarLogin)

## 구현 내용
- `SessionTimer.tsx`(138라인 신규)로 사용자 활동 기반 세션 만료 카운트다운과 초기화 로직을 구현하고, `Toast.tsx` 알림 컴포넌트를 함께 추가했다.
- 로그인 로직을 컴포넌트에서 분리하여 `api/axios/auth.ts`, `api/queries/useAuth.ts`, `api/types/auth.type.ts`로 재구성했다. `Login.tsx`는 260여 라인에서 대폭 축소되어 뷰 책임만 남겼다.
- 로그인 성공 후 권한/역할에 따른 리다이렉트 처리를 정비했다.
- 차량 접수 모듈용 별도 로그인 화면(`CarLogin.tsx`)을 추가했다.
