# 용어사전과 번역 기능

## 개요
중국/해외 거래처 대응을 위한 다국어 번역과, 업무 용어를 통일 관리하는 용어사전(Glossary) 기능을 개발했다. 초기 외부 번역 라이브러리를 사용하다가 이를 제거하고 자체 용어사전 기반 번역 유틸리티로 전환했다.

## 주요 커밋
- `2025-09-22` `a52d899` 용어사전 페이지 개발 (Glossary 272라인 신규) / `0b5da0d` 용어사전 번역 기능 추가
- `2025-09-24` `ac31ff7` 용어사전 엑셀 다운·내보내기 기능 개발
- `2025-10-10` `c7b0ae5` 기존 번역 라이브러리 제거 및 자체 번역 전환 (GoogleTranslator 705라인 정리, glossaryTranslator 도입)
- `2026-01-28` `f0eea17` 테이블 헤더 번역 가능하게 수정 / `2026-02-03` `752f3f1` 번역 기능 수정

## 구현 내용
- 용어사전 페이지(`Glossary.tsx`)에서 용어를 등록/조회하고 엑셀로 내보내기/가져오기를 지원했다.
- 기존 GoogleTranslator 기반 라이브러리를 제거하고, 용어사전을 기반으로 하는 `utils/glossaryTranslator.ts`로 번역 로직을 전환하여 업무 용어의 번역 일관성을 확보했다.
- 테이블 헤더 등 정적 UI 텍스트도 번역 대상이 되도록 확장했다.

## 관련 파일
