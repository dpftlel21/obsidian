# 메인 대시보드 화면 개선

## 개요
로그인 후 처음 보게 되는 메인 화면(대시보드)을 개발/개선했다. 공지·Q&A·자료실 요약과 납품현황 데이터를 한 화면에 모으고, 리스트 클릭 시 상세로 이동하는 진입 허브로 구성했다.

## 주요 커밋
- `2025-03-18` `5430846` Main 화면 UI 개발 (초기)
- `2025-07-29` `44ec0d7` 메인 화면 개선 및 리스트 클릭시 detail 조회 (EnDatePicker 564라인 신규)
- `2025-07-30` `c1f9d76` 메인페이지 납품현황 데이터 조회 구현 / `8954548` 첨부파일 갯수 count 추가
- `2025-05-30` `a050d71`·`20bb977` 메인화면 UI 수정

## 구현 내용
- 메인 화면에 공지/Q&A/자료실 최신 목록과 납품현황 요약을 배치하고, 각 리스트 항목 클릭 시 해당 상세로 이동하도록 연결했다.
- 조회 조건용 날짜 선택기(`EnDatePicker.tsx`, 564라인)를 자체 구현해 메인 및 조회 화면 전반에 사용했다.
- 게시글의 첨부파일 개수를 카운트해 목록에 표시했다.
- 거래처(vendor)와 관리자(parts) 메인을 구조적으로 분리했다.
