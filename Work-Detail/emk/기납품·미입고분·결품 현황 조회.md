# 기납품·미입고분·결품 현황 조회

## 개요
납품 현황을 다각도로 조회하는 화면군을 개발했다. 이미 납품된 내역(기납품), 아직 입고되지 않은 물량(미입고분), 부족 물량(결품)을 각각 조회하고 총계·엑셀 다운로드를 제공한다.

- `2026-03-09` `09ae2b3` 미입고분현황 조회 기능 개발 / `2026-03-13` `09ae2b3`

- `2026-07-14` `1293fe0` 납품현황 항공 로직 수정 / `2026-07-20` `699e2d1` 결품현황 검색 조건 일자 및 필터 수정 / `0f60090` 미입고분 현황 메뉴 수정

## 구현 내용
- 기납품내역 조회(`DeliveryGoods.tsx` 193라인 신규)를 구현하고 합계 행(총계)을 추가했다.
- 미입고분현황 화면을 개발하고 그리드 컬럼을 보정한 뒤 엑셀 다운로드를 붙였다.
- 결품현황의 검색 조건(일자/필터)을 실무에 맞게 수정하고, 납품현황의 항공/내륙 운송 구분 로직을 보정했다.
