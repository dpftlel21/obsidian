# 납품서 작성·조회와 바코드 스캐너

## 개요
거래처가 납품 시 작성하는 납품서(Delivery Note)의 작성/조회/생성 화면을 개발했다. 현장 입력 편의를 위해 바코드 스캐너로 품번·수량을 읽어들이는 기능과, 엑셀 업로드/다운로드를 함께 구현했다.

## 구현 내용
- `DeliveryNote.tsx`를 중심으로 납품서 작성 폼과 그리드 입력을 구현하고, API(`api/axios/delivery.ts`, `useDelivery.ts`)와 연동했다.
- `BarcodeScannerTable.tsx`(457라인)로 바코드 스캔 입력을 처리하고, 스캔 결과에 따른 수량 계산 로직을 구현했다.
- 납품서 목록 조회와 상세를 제공하고, 엑셀 업로드로 대량 생성/다운로드로 내보내기를 지원했다.
- 입고일 존재 여부에 따라 파일 업로드/수정을 제한하는 업무 규칙을 반영했다.
