# 메뉴 권한 관리와 관리자·사용자 화면 분리

## 개요
사용자 권한(admin/emk 관리자 vs 거래처 사용자)에 따라 노출 메뉴와 접근 가능한 화면을 분리하고, 권한별 메뉴 매핑을 관리하는 기능을 개발했다. React 앱을 `vendor`(거래처)와 관리자용 구조로 나누는 아키텍처 기반이 되었다.

## 주요 커밋
- `2025-03-31` `99b56ef` 메뉴 권한 조회
- `2025-05-08` `605ad29` 사용자 메뉴 분리 / `ca10401` 관리자(emk) 메뉴 전환 구현
- `2025-05-09` `26e9c88` 사용자 권한에 따른 메뉴 분리 / `31cb132` 사용자 메뉴 변경
- `2025-05-14` `4e421b8` URL 접근 제어 추가
- `2025-06-11` `b7581fe` 주문등록 저장(권한 메뉴 PermissionTable/PermissionMenuItem 개선 포함)

## 구현 내용
- 권한 조회 API(`api/axios/permission.ts`, `usePermission.ts`)를 통해 역할별 메뉴 트리를 받아 사이드바/메가메뉴에 반영했다.
- 관리자(emk)와 거래처(vendor) 화면을 별도 구조로 분리하여 동일 앱에서 역할에 맞는 화면만 렌더링하도록 했다.
- URL 직접 접근을 제어하여 권한 없는 화면으로의 진입을 차단했다.
- 권한 편집용 `PermissionTable.tsx`, `PermissionMenuItem.tsx`로 메뉴별 권한을 체크박스 트리로 관리하도록 했다.
