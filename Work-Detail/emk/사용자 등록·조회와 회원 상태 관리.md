# 사용자 등록·조회와 회원 상태 관리

## 개요
ERP 사용자(거래처/직원) 계정을 등록·조회하고, 비밀번호 변경·회원 미사용/철회 등 계정 생명주기를 관리하는 화면을 개발했다.

## 주요 커밋
- `2025-03-20` `e761697` 사용자 등록 화면 추가
- `2025-03-25` `b93c8b0` 사용자 등록 아이디 바인딩 / `017b326` 사용자 정보 저장
- `2025-03-26` `eddea74` 사용자 조회 / `3b38f47` 사용자 정보 조회
- `2025-03-27` `c580b6c`·`2985efa` 비밀번호 변경 UI / `e21c9b1` 비밀번호 변경 추가
- `2025-03-27` `58ee1c2` 회원 미사용 처리 구현 / `3c0b88a` 회원 철회 구현
- `2025-04-01` `0441a7e`·`da5c414` 권한 업데이트 구현

## 구현 내용
- 사용자 등록 폼(`UserForm.tsx`)과 조회 폼(`SearchForm.tsx`)을 구성하고, 아이디 중복/바인딩과 저장 로직을 연동했다.
- 비밀번호 변경 UI를 별도로 제공하여 계정 보안을 강화했다.
- 회원 상태를 "미사용", "철회"로 전환하는 처리로 퇴사/거래종료 계정을 소프트 관리할 수 있게 했다.
- 사용자별 권한 업데이트 기능으로 계정 생성 이후 권한을 조정할 수 있게 했다.
