# 게시판·공지사항 시스템과 필터링

## 개요
공지사항을 비롯한 게시판(공지/업체 게시판) 기능을 개발했다. 글 등록/조회/상세/수정과 종류별 글쓰기, 필터링·검색, 파일 첨부까지 포함한 범용 게시판 컴포넌트를 구축했다.

## 주요 커밋
- `2025-04-09` `77b0976` 공지사항 글 등록 개발 / `798f786` 공지사항 글 생성
- `2025-04-11` `ab59904` 게시판 필터링 기능 개발 (BoardFilterBar 신규)
- `2025-04-14` `dc0ccee` 게시판 종류별 글쓰기 추가 및 UI 수정
- `2025-04-16` `2088d08` 공지사항 디테일 수정
- `2025-07-01` `9fe504d` 업체 게시판 전체·상세 조회 및 업로드 / `4440fe1` 파일다운로드 및 게시판 수정 기능

## 구현 내용
- 공통 게시판 컴포넌트군(`BoardAll`, `BoardList`, `BoardDetail`, `BoardWrite`, `BoardSearch`, `BoardPagination`)을 구성하여 여러 게시판에서 재사용하도록 했다.
- `BoardFilterBar.tsx`(134라인 신규)로 카테고리/조건 필터링을 추가하고, 검색과 결합해 목록을 좁힐 수 있게 했다.
- 게시판 종류별로 글쓰기 폼을 분기하고, 공지/업체 게시판의 상세·수정·삭제·파일 첨부/다운로드를 지원했다.
- 게시판 접근을 헤더/메가메뉴 권한과 연동했다.
