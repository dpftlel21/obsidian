# 차량 접수·검사 시스템

## 개요
차량 검사/접수 업무를 위한 모바일 친화 화면을 개발했다. 차대번호(VIN)·발행번호 조회, 부품 팝업, 검사 항목 테이블, 이미지 촬영/업로드, 복사 기능까지 포함하는 현장 입력 시스템이다.

## 구현 내용
- 차량 접수 화면(`CarRegister.tsx`)과 검사 항목 그리드(`InspectionTable.tsx`)를 개발하고, VIN 팝업(`VinPop.tsx`)·부품 팝업(`PartsPop.tsx`)을 연동했다.
- 이미지 조회 API(`api/axios/imgSearch.ts`, `useImgSearch.ts`)를 통해 차대번호/발행번호 기준 이미지를 연결했다.
- 차대번호 유효성 검사와 작업 시작일자, 차량번호 컬럼 등 검사 실무 필드를 추가했다.
- 기존 검사 데이터를 복사해 신규 접수를 빠르게 생성하는 기능을 제공했다.
