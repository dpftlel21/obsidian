# 주문등록과 임시저장·주문확정 워크플로우

## 개요
거래처의 주문 등록 화면과, 작성 중인 주문을 임시저장했다가 이어서 확정하는 업무 흐름을 개발했다. 상용주문(FreqOrderReg) 등록, 품번 팝업 바인딩, 임시저장 이력 관리, 주문확정 및 권한 처리까지 포함한다.

## 주요 커밋
- `2025-05-20` `6555c56` 주문등록 화면 구현 (FreqOrderReg 325라인 신규) / `79c14ad` 품번 팝업 바인딩
- `2025-05-22` `3126b00` 주문현황 화면 개발
- `2025-06-11` `b7581fe` 주문등록 저장·임시저장 / `e4f4b0f` 임시저장 이력 및 상세 조회 / `631fdbf` 임시저장 / `5012756` 임시저장 주문확정 구현
- `2025-08-18` `ad823b7` 주문확정 버튼 생성 및 권한 처리
- `2026-03-27` `3e1da0c` 주문 등록 조건 수정 및 주문현황 조건·컬럼 추가

## 구현 내용
- 주문등록 컴포넌트(`FreqOrderReg.tsx`)에서 품번 검색 팝업(`SearchPartsInfo`)을 통해 품목을 바인딩하고 그리드로 수량을 입력받도록 했다.
- 주문 API(`api/axios/orderReg.ts`, `useOrderReg.ts`)와 타입(`orderReg.type.ts`)을 정의했다.
- 임시저장/이력 조회/상세/개별 삭제와, 임시저장분을 불러와 주문확정으로 전환하는 흐름을 구현했다.
- 주문확정 버튼에 권한 처리를 붙여 확정 권한이 있는 사용자만 확정할 수 있게 했다.
