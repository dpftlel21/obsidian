# 커스텀 그리드 테이블 컴포넌트

## 개요
ERP 전반의 데이터 그리드에 재사용되는 공통 테이블 컴포넌트를 자체 개발했다. 드래그앤드롭, 셀 복사/붙여넣기, 컬럼 폭 리사이징, 페이지네이션, 검색폼을 하나의 그리드 체계로 묶어 이후 모든 조회/입력 화면의 기반이 되었다.

## 주요 커밋
- `2025-04-18` `fcd8c60` 테이블 드래그앤드롭, 복사붙여넣기 구현 (GridTable 548라인 신규)
- `2025-05-19` `fe5f755` 테이블 컬럼 넓이 리사이징 기능 추가 / `6474d07` 리사이징 기능 수정
- `2025-05-27` `082ef7e` 테이블 스타일 수정

## 구현 내용
- `GridTable.tsx`(548라인)를 중심으로 `GridSearchForm.tsx`, `GridPagination.tsx`, `interface.ts`, `styles/style.ts`로 구성된 그리드 패키지를 만들었다.
- 엑셀 유사 UX: 셀 드래그 선택, 복사(Ctrl+C)·붙여넣기(Ctrl+V), 행 드래그앤드롭 재정렬을 지원했다.
- 컬럼 헤더 경계 드래그로 폭을 조절하는 리사이징 기능을 추가했다.
- 검색폼과 페이지네이션을 그리드와 결합해 조회 화면 공통 패턴을 확립했다.

## 관련 파일
- `frontend/src/common/grid/GridTable.tsx`, `GridSearchForm.tsx`, `GridPagination.tsx`
- `frontend/src/common/grid/interface.ts`, `frontend/src/common/grid/styles/style.ts`
