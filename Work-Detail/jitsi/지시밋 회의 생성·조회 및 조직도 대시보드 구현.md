# 지시밋 회의 생성·조회 및 조직도 대시보드 구현

## 개요
Jitsi 기반 사내 화상회의 플랫폼(지시밋)의 핵심 진입 화면인 대시보드에서 회의를 생성하고 목록을 조회하는 기능을 구축했다. 조직도(orgchart) 데이터를 연동해 회의 생성 시 참석자를 조직 구조에서 직접 선택할 수 있도록 했다.

## 관련 커밋
- `2026-05-19` `6dcd1ef` 지시밋 회의 생성 및 조회 기능 개발

## 주요 구현 내용
- **회의 API 계층 신설**: `kd_features/api/meeting/meetingApi.ts`와 `hooks/useMeetingList.ts`, `useMeetingAttendees.ts`를 추가해 회의 목록·참석자 조회를 React Query 훅으로 캡슐화했다.
- **조직도 컴포넌트 구축**: `kd_features/orgchart/CustomOrgChart.tsx`(약 770줄)와 전용 `icons.tsx`, `styles.ts`를 신규 작성해 조직 트리 기반 UI를 제공했다. 회의 참석자 선택의 기반이 된다.
- **대시보드 재구성**: `kd-dashboard/components/web/DashboardMainContent.tsx`, `KdDashboard.tsx`, `DashboardSidebar.tsx`, `CreateMeetingDialog.tsx`를 대폭 개편(styles.ts 약 883줄 증가)해 회의 생성 다이얼로그와 목록 뷰를 통합했다.
- **PWA/미디어 설정**: `media-config.js` 신설, `pwa-worker.js` 조정으로 앱 실행 환경을 정비했다.

## 규모
20개 파일 변경, 약 +3,610 / -294 라인. 이 커밋이 지시밋 프론트엔드의 대시보드 골격을 형성했다.
