# 반응형·모바일 대응 및 번들 성능 최적화

## 개요
데스크톱 위주로 개발된 화면을 모바일·태블릿에서도 쓸 수 있도록 반응형으로 정비하고, 커진 번들 크기와 대시보드/미디어 기본값을 최적화해 성능을 확보했다.

## 관련 커밋
- `2026-06-26` `8de2e21` 반응형 UI 수정
- `2026-07-21` `d42b8d1` perf(meeting): 대시보드·미디어 기본값 최적화
- `2026-07-21` `e7881c6` build(webpack): 메인 번들 성능 예산 상향
- `2026-07-21` `70d83ae` build(webpack): 번들 예산 초과를 비차단 처리

## 주요 구현 내용
- **반응형 스타일 대개편**: `8de2e21`에서 대시보드 `styles.ts`(약 +567라인)와 `KdDashboard.tsx`, 캘린더 스타일을 손봐 화면 폭에 따른 레이아웃을 정리했다(약 +1,794 / -398 라인).
- **다이얼로그·설정 모바일 대응**: `cff7a5b`에서 `BaseDialog.tsx`, `DialogWithTabs.tsx`, 오디오/비디오 설정 콘텐츠, `Drawer.tsx`를 모바일·태블릿에 맞게 조정했다.
- **성능 최적화**: `d42b8d1`에서 `config.js`/`prod-config.js`의 미디어 기본값과 대시보드 렌더링을 최적화(약 +358 / -228 라인)하고, 관련 작업 목록을 `docs/codex-performance-optimization-tasks.md`로 정리했다.
- **번들 예산 조정**: `webpack.config.js`의 성능 예산을 상향하고 예산 초과를 빌드 실패가 아닌 경고로 처리해 배포 파이프라인을 안정화했다.
