# 회의 로비(대기실) 승인 입장 시스템 구현

## 개요
참가자가 회의실에 바로 들어가지 않고 로비(대기실)에서 방장의 승인을 기다렸다가 입장하는 흐름을 구현했다. 또한 방장이 아직 입장하지 않은 회의실에서는 참가자를 로비에 대기시키는 정책을 추가했다.

## 관련 커밋
- `2026-05-26` `cf7da26` 참가자 권한 승인 후 입장 로직(로비) 개발
- `2026-05-27` `b0ed33f` 회의실 방장 없을 때 참가자 로비 대기 기능 개발
- `2026-05-27` `cba4d04` 로비 대기방 영어 문구 수정

## 주요 구현 내용
- **로비 전용 모듈 신설**: `kd_features/lobby/` 하위에 `middleware.ts`, `prejoinGuard.ts`, `actions.ts`, `reducer.ts`, `actionTypes.ts`를 구성해 로비 상태와 입장 가드를 관리했다. `prejoinGuard.ts`(약 131줄)가 입장 전 조건을 판정한다.
- **라우팅·미들웨어 연동**: `features/app/getRouteToRender.web.ts`, `middlewares.any.ts`에서 인증·회의 상태에 따라 로비 화면으로 라우팅하도록 했다.
- **방장 부재 대기 로직**: `b0ed33f`에서 `lobby/middleware.ts`에 방장 미입장 시 참가자 대기 처리를 추가하고, `features/lobby/components` 및 `prejoin/actions.web.ts`에 연결했다. 다국어 문구(`lang/main-ko.json`, `main.json`)도 함께 추가했다.
- **입장 자격 확인 API**: `kd_features/api/meeting/hooks/useMeetingJoin.ts`, `useMeetingStatus.ts`로 서버측 입장 가능 여부를 확인한다.
