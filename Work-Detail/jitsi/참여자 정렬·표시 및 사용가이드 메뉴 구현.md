# 참여자 정렬·표시 및 사용가이드 메뉴 구현

## 개요
회의 참가자를 이름·부서 등 기준으로 정렬하고 신원(이름·부서)을 명확히 표시하는 기능, 그리고 사용자가 기능을 익힐 수 있는 사용가이드 메뉴를 구현했다.

## 관련 커밋
- `2026-06-15` `b0abcb4` 참가자 정렬 기능 추가 및 방 로고·타이틀 변경
- `2026-07-22` `f55d908` 회의자 이름 및 부서 표시 및 기타 기능 추가
- `2026-07-27` `ef7b31d` 정렬 기능 수정
- `2026-07-31` `c734459` 사용가이드 메뉴 개발
- `2026-08-12` `ad5a1d1` 참여자 선택 UI 수정 및 메뉴얼 변경

## 주요 구현 내용
- **참가자 정렬**: `kd_features/participant-sort/` 모듈(`functions.ts`, `selectors.ts`, `functions.test.mjs`)과 `ParticipantSortControls.tsx`를 신설해 정렬 기준을 선택·적용하도록 했다.
- **참가자 신원 표시**: `ParticipantIdentity.tsx`에서 이름·부서를 필름스트립/썸네일에 표시했다.
- **사용가이드**: `c734459`에서 `guide.html`(약 760줄)과 `images/guide/` 스크린샷을 추가해 기능 사용법을 안내하는 가이드 메뉴를 구축했다.
- **메뉴얼·선택 UI 정비**: `ad5a1d1`에서 참여자 선택 UI와 메뉴얼 문구를 다듬었다.
