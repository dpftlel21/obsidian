# JWT 토큰 인증 및 방장·참가자 권한 체계 구축

## 개요
화상회의 입장 시 사용자를 방장(owner)과 일반 참가자(member)로 구분하는 권한 체계를 JWT 토큰 기반으로 구축했다. 토큰 발급·검증·URL 파라미터 처리, 호스트 검증 로직을 여러 차례 수정하며 안정화했다.

## 관련 커밋
- `2026-05-19` `56ddb90` 토큰 인증 로직 수정
- `2026-05-19` `797140e` 호스트 검증 로직 개선
- `2026-05-19` `f4d2968` 토큰 수정
- `2026-05-20` `757a1cb` Auth API 로직 분기 수정
- `2026-05-20` `0d8a0c1` / `4857b7b` 토큰 및 토큰 URL 수정
- `2026-05-20` `c4c5b75` URL 오너·멤버 권한 수정
- `2026-05-20` `6079c2c` 방장 권한 수정
- `2026-05-21` `ed2447c` / `b027961` 방장·참가자 권한 문제 수정

## 주요 구현 내용
- **JWT 미들웨어 분기**: `features/base/jwt/middleware.any.ts`에서 토큰에 담긴 오너/멤버 정보를 읽어 권한을 분기 처리했다.
- **토큰 저장·복원**: `kd_features/api/auth/tokenStorage.ts`를 중심으로 토큰 저장 로직을 정비하고 대시보드 진입(`KdDashboard.tsx`)에서 인증 상태에 따라 화면을 분기했다.
- **호스트 검증 설정화**: `config-override.js`, `dev-config.js`, `prod-config.js`에 호스트 검증 관련 설정을 추가(797140e에서 3개 config에 약 +264라인)해 환경별로 동작을 제어할 수 있게 했다.
