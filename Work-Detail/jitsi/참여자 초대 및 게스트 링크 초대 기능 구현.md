# 참여자 초대 및 게스트 링크 초대 기능 구현

## 개요
사내 사용자를 회의에 초대하는 기능과, 계정이 없는 외부 게스트를 링크로 초대해 로비를 거쳐 입장시키는 두 갈래의 초대 흐름을 구축했다.

## 관련 커밋
- `2026-05-27` `e3a5e9d` 참여자 초대 기능 개발
- `2026-06-10` `90068b0` 사용자 링크 초대 기능 개발
- `2026-07-23` `d55bc3d` 게스트 초대 기능 URL 수정

## 주요 구현 내용
- **사내 사용자 초대**: `features/invite/actions.any.ts`와 `add-people-dialog/web/InviteKdUsersSection.tsx`(약 133줄)를 신설해 기존 AddPeopleDialog에 KD 사용자 초대 섹션을 통합했다. 초대 대상은 회의 API(`meetingApi.ts`)로 서버에 반영된다.
- **게스트 링크 초대**: `kd_features/api/meeting/guestInviteApi.ts`(약 140줄)와 `GuestInviteLinkSection.tsx`, `GuestInviteLobby.web.tsx`를 추가해 게스트용 초대 링크 생성·입장 경로를 구현했다. `getRouteToRender.web.ts`에 게스트 라우팅을 추가.
- **URL 로직 분리·테스트**: `d55bc3d`에서 URL 생성 로직을 `guestInviteUrl.ts`(약 148줄)로 분리하고 `guestInviteApi.test.mjs`, 관련 테스트를 추가해 안정화했다.
