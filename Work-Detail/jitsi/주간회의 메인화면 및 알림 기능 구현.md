# 주간회의 메인화면 및 알림 기능 구현

## 개요
지시밋(주간회의) 서비스의 메인/랜딩 화면 UI를 구축하고, 이후 회의 관련 알림 기능을 추가했다. 초기 랜딩 설계부터 메인 회의 목록 재설계, 알림까지 사용자 진입 경험을 다듬은 작업이다.

## 관련 커밋
- `2026-05-15` `a65ac96` KD 메인 랜딩 페이지 추가
- `2026-05-15` `2cf4250` KD 메인 회의 목록 재설계
- `2026-05-15` `39b9398` 주간회의 메인화면 UI 개발
- `2026-05-18` `125c3b2` 메인화면 UI 개발
- `2026-07-21` `7646a24` 메인 화면 UI 개발 및 빌드 수정
- `2026-07-21` `7a1dd77` 알림 기능 개발

## 주요 구현 내용
- **랜딩·메인 화면**: KD 메인 랜딩 페이지와 회의 목록 화면을 구성하고 여러 차례 재설계하며 정보 구조를 정리했다.
- **알림 기능**: `7a1dd77`에서 회의 관련 알림 표시 흐름을 추가했다.
