# 관리자 대시보드 트래픽 모니터링(Grafana) 구축

## 개요
운영자가 회의 서비스의 트래픽과 상태를 파악할 수 있도록 관리자 대시보드에 트래픽 추적·모니터링 기능을 단계적으로 구축했다. UI → API 연동 → Grafana 연동 → 부하테스트(k6) 순으로 발전했다.

## 관련 커밋

- `2026-07-16` `b71221c` 관리자 대시보드 알람 및 트래픽 추적 API 연동
- `2026-07-20` `10930f7` 메인화면 UI 개선 및 Grafana 트래픽 추적 기능 개발
- `2026-07-20` `ad2c133` k6 부하테스트 수정

## 주요 구현 내용
- **모니터링 UI**: 관리자 대시보드(`MeetingAdminDashboard.tsx` 등)에 트래픽 차트와 상태 지표 화면을 구성했다.
- **API 연동 및 알람**: `b71221c`에서 트래픽 추적 API를 붙이고 임계치 기반 알람을 연동했다.
- **Grafana 연동**: `10930f7`에서 Grafana 트래픽 추적을 붙여 실제 운영 지표를 대시보드에서 확인할 수 있게 했다.
- **부하 검증**: k6 스크립트를 추가·수정해 트래픽 부하 상황을 재현·측정했다.
