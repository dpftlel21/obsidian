# 승무팀장 평가 및 설문 API

## 개요
buspia 모듈에서 승무팀장 평가와 설문(survey) 관련 API를 개발한 작업이다. 설문 리스트/상세 조회, 평가 메인 화면 조회, 설문 저장, 결과 상세 조회까지 평가 업무 흐름 전반을 `app/api/buspia/router.py`·`service.py`에 구현했다.

## 주요 변경/구현
- **설문 리스트 조회 API** (`1d327ce`): 승무팀장평가 설문 목록 조회 API를 신설(가장 초기 작업).
- **평가 메인 화면 조회 API** (`d9a455b`): 승무팀장 평가 메인 화면용 조회 API를 추가.
- **설문 저장하기 API** (`af43b99`): 설문 응답 저장 API(`service.py` +62 규모)를 추가하고, `387cb22`에서 저장 조건에 `FIN_YN`(완료 여부) 처리를 포함하도록 보정.
- **설문 결과 상세 조회** (`ead6ad7`): 설문 결과 상세 조회 쿼리와 API를 개발.
- **설문 detail 조회 조건 보정** (`f3f4531`, `b9e8bb6`, `a4dd963`, `b6b0758`): 설문 상세 조회의 조건절을 여러 차례에 걸쳐 반복 수정. (자세한 경위는 [[설문 상세 조회 조건 반복 수정]] 참고)
