# 관리자 대시보드 트래픽 추적 및 서버 모니터링

## 개요
관리자 대시보드용 백엔드를 구축한 작업이다. 서버 트래픽 추적, CPU/RAM 등 서버 스펙 조회, Prometheus 연동, 회의 품질 조회까지 운영 모니터링에 필요한 API를 `admin_router.py`·`admin_service.py`에 집중 개발했다.

## 주요 변경/구현
- **트래픽 추적 API 개발** (`6340559`): `admin_service.py`(+535 규모)에 트래픽 추적 서비스를 신설하고 `admin_router.py`에 엔드포인트를 추가. 설계 문서 `phase2.md`를 함께 작성했다.
- **관리자 대시보드 추가 기능(트래픽 추적)** (`b398e58`): `models.py`·`schemas.py`에 대시보드 엔터티를 추가하고 `admin_service.py`(+447 규모)를 확장, `meeting-admin-phase1-ddl.sql`로 DDL을 정의했다.
- **관리자 대시보드 로직 수정** (`81f4343`): 대시보드 집계 로직 보정.
- **신규 트래픽 추적 및 로그 관리 API** (`6e5741e`): `admin_service.py`(+458 규모)에 트래픽/로그 관리 기능을 추가.
- **프로메테우스 API** (`7f30a17`): `admin_service.py`에 Prometheus 메트릭 연동을 추가하고 `7bea0ea`에서 트래픽 추적을 후속 보정.
- **CPU, RAM 등 서버 스펙 조회 API** (`ce61cd1`): 서버 리소스 점유율 조회 API를 구현하고 `admin-dashboard.md` 문서를 대폭 개정.
- **전체 회의 품질 조회** (`90711fe`): 활성 회의 품질 지표 조회 API와 스펙 문서(`meeting-quality-active-meetings-api-spec.md`)를 추가.
