# 실시간 알림 및 공지 시스템

## 개요
화상회의 모듈의 알림(notification)·공지(notice) 시스템을 구축한 작업이다. 알림 이벤트 발행, 읽음 처리, 공지 브로드캐스트, 재수정 회의 알림 등 사용자 통지 흐름을 담당한다.
