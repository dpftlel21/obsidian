# K6 부하 테스트 및 서버 허용치 예측

## 개요
화상회의 서버의 트래픽 과부하를 검증하기 위한 K6 부하 테스트 API와, 과거 회의 데이터를 기반으로 서버 허용치를 통계적으로 예측하는 기능을 개발한 작업이다.

## 주요 변경/구현
- **K6 트래픽 과부하 API** (`d37b30a`): `loadtest_service.py`(+291 규모)를 신설해 K6 부하 테스트 실행/제어 로직을 구현하고 `admin_router.py`에 엔드포인트를 연결했다.
- **k6 API 바인딩 수정** (`f7943df`): K6 API 파라미터 바인딩 오류를 보정.
- **과거 회의 기반 서버 허용치 통계 예측 API** (`cbb5777`): `admin_service.py`(+163 규모)에 과거 회의 데이터 기반 허용치 예측 로직을 추가하고, 부하 테스트 관련 코드를 `loadtest_service.py`에서 정리(-155)했다. 결과 리포트 프론트 가이드(`meeting-outcome-report-frontend-guide.md`)를 함께 작성.
