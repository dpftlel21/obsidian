# 파일 업로드 UX 개선 프로젝트 상세

## 프로젝트 개요
- **기간**: 2026년 3월 (약 2주)
- **목적**: 파일 업로드 사용자 경험 전면 개선
- **난이도**: ⭐⭐⭐ (보통)

## 초기 문제 현황

### UX 문제점들
1. **드래그 앤 드롭 감도 문제** - 드래그 영역 인식 불안정
2. **25개 제한 로직 부재** - 무제한 업로드로 인한 성능 저하
3. **파일 미리보기 깨짐** - 이미지/PDF 미리보기 오류
4. **모바일 반응형 엉망** - 모바일에서 사용성 극히 불편

### 2. 파일 갯수 제한 로직 (3월 25일)
```javascript
const addFiles = useCallback((newFiles: File[]) => {
  setSelectedFiles(prev => {
    const combined = [...prev, ...newFiles]
    if (combined.length > 25) {  // 25개 제한
      showToast(`최대 25개까지 업로드할 수 있습니다.`, 'warning')
      return combined.slice(0, 25)
    }
    return combined
  })
}, [showToast])
```

**개선 효과:**
- 성능 저하 방지
- 명확한 사용자 안내
- 시스템 안정성 향상

// 파일 미리보기에 확대/축소 추가
const handleWheel = (e: WheelEvent) => {
  if (e.ctrlKey) {
    e.preventDefault()
    const delta = e.deltaY > 0 ? -0.1 : 0.1
    setZoom(prev => Math.min(Math.max(prev + delta, 0.5), 3))
  }
}

useEffect(() => {

const generatePreview = useMemo(() => {
  if (file.type.startsWith('image/')) {
    return URL.createObjectURL(file)
  } else if (file.type === 'application/pdf') {
    return `/api/pdf-preview?file=${encodeURIComponent(file.name)}`
  }
  return null
}, [file])

// 메모리 누수 방지
