### 1. 전역 상태 관리 시스템 (loadingStore.ts)

```typescript
interface LoadingState {
  globalLoading: boolean;                    // 전역 로딩 상태
  loadingStates: Record<string, boolean>;    // 컴포넌트별 로딩 상태
  loadingMessage: string;                    // 로딩 메시지
}

const useLoadingStore = create<LoadingState>()(
  immer((set, get) => ({
    globalLoading: false,
    loadingStates: {},
    loadingMessage: '',
    
    // 전역 로딩 제어
    setGlobalLoading: (loading: boolean, message?: string) => {
      set((state) => {
        state.globalLoading = loading;
        if (message !== undefined) state.loadingMessage = message;
      });
    },
    
    // 컴포넌트별 로딩 제어
    setComponentLoading: (key: string, loading: boolean) => {
      set((state) => {
        if (loading) {
          state.loadingStates[key] = true;
        } else {
          delete state.loadingStates[key];
        }
      });
    },
    
    // 로딩 상태 확인
    hasAnyLoading: () => {
      const state = get();
      return state.globalLoading || Object.keys(state.loadingStates).length > 0;
    },
    
    // 모든 로딩 상태 초기화
    clearAllLoading: () => {
      set((state) => {
        state.globalLoading = false;
        state.loadingStates = {};
        state.loadingMessage = '';
      });
    },
  }))
);
```

**핵심 로직**:
- Zustand + Immer로 불변성과 성능 보장
- 전역/컴포넌트별 로딩 상태 분리 관리
- 메모리 누수 방지 (로딩 완료 시 상태 삭제)

### 2. 이미지 최적화 컴포넌트 (OptimizedImage.tsx)

```typescript
interface OptimizedImageProps {
  src: string;
  alt: string;
  className?: string;
  fallbackSrc?: string;
  lazy?: boolean;
  sizes?: string;
  srcSet?: string;
}

export const OptimizedImage: React.FC<OptimizedImageProps> = ({
  src,
  alt,
  className = '',
  fallbackSrc = '/images/placeholder.png',
  lazy = true,
  sizes,
  srcSet,
}) => {
  const [isLoaded, setIsLoaded] = useState(false);
  const [hasError, setHasError] = useState(false);
  const [isVisible, setIsVisible] = useState(!lazy);
  const imgRef = useRef<HTMLImageElement>(null);

  // Intersection Observer로 지연 로딩
  useEffect(() => {
    if (!lazy || isVisible) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setIsVisible(true);
          observer.disconnect();
        }
      },
      { threshold: 0.1, rootMargin: '50px' }
    );

    if (imgRef.current) {
      observer.observe(imgRef.current);
    }

    return () => observer.disconnect();
  }, [lazy, isVisible]);

  const handleLoad = () => {
    setIsLoaded(true);
    setHasError(false);
  };

  const handleError = () => {
    setHasError(true);
    setIsLoaded(false);
  };

  return (
    <div className={`relative overflow-hidden ${className}`}>
      {!isLoaded && !hasError && (
        <div className="absolute inset-0 bg-gray-200 animate-pulse" />
      )}
      
      <img
        ref={imgRef}
        src={isVisible ? (hasError ? fallbackSrc : src) : undefined}
        srcSet={isVisible ? srcSet : undefined}
        sizes={sizes}
        alt={alt}
        onLoad={handleLoad}
        onError={handleError}
        className={`
          transition-opacity duration-300
          ${isLoaded ? 'opacity-100' : 'opacity-0'}
          ${className}
        `}
      />
    </div>
  );
};
```

**핵심 기능**:
- **지연 로딩**: IntersectionObserver로 뷰포트 진입 시만 로딩
- **에러 처리**: fallback 이미지 자동 적용
- **반응형 이미지**: srcSet, sizes 속성 지원
- **로딩 애니메이션**: 스켈레톤 + fade-in 효과

### 3. 스켈레톤 로딩 시스템 (Skeleton.tsx)

```typescript
interface SkeletonProps {
  variant?: 'text' | 'rectangular' | 'circular';
  width?: string | number;
  height?: string | number;
  lines?: number;
  className?: string;
  animated?: boolean;
}

export const Skeleton: React.FC<SkeletonProps> = ({
  variant = 'text',
  width = '100%',
  height,
  lines = 1,
  className = '',
  animated = true,
}) => {
  const baseClasses = `
    bg-gray-200 
    ${animated ? 'animate-pulse' : ''}
    ${className}
  `;

  const getVariantClasses = () => {
    switch (variant) {
      case 'circular':
        return 'rounded-full';
      case 'rectangular':
        return 'rounded-md';
      case 'text':
      default:
        return 'rounded';
    }
  };

  const getDefaultHeight = () => {
    switch (variant) {
      case 'text':
        return '1rem';
      case 'circular':
        return width;
      default:
        return '1.25rem';
    }
  };

  const skeletonHeight = height || getDefaultHeight();
  
  if (variant === 'text' && lines > 1) {
    return (
      <div className="space-y-2">
        {Array.from({ length: lines }).map((_, index) => (
          <div
            key={index}
            className={`${baseClasses} ${getVariantClasses()}`}
            style={{
              width: index === lines - 1 ? '75%' : width,
              height: skeletonHeight,
            }}
          />
        ))}
      </div>
    );
  }

  return (
    <div
      className={`${baseClasses} ${getVariantClasses()}`}
      style={{ width, height: skeletonHeight }}
    />
  );
};
```

**특징**:
- **다양한 형태**: text, rectangular, circular 지원
- **멀티 라인**: 텍스트 블록을 위한 여러 줄 지원
- **커스터마이징**: 크기, 애니메이션, 스타일 조절 가능

```typescript
interface ErrorBoundaryState {
  hasError: boolean;
  error: Error | null;
}

export class ErrorBoundary extends Component<
  PropsWithChildren<{ fallback?: ReactNode }>,
  ErrorBoundaryState
> {
  constructor(props: PropsWithChildren<{ fallback?: ReactNode }>) {
    super(props);
    this.state = { hasError: false, error: null };
  }

  static getDerivedStateFromError(error: Error): ErrorBoundaryState {
    return { hasError: true, error };
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    // 에러 로깅 (개발/운영 환경 분리)
    if (process.env.NODE_ENV === 'development') {
      console.error('ErrorBoundary caught an error:', error, errorInfo);
    } else {
      // 운영 환경에서는 에러 트래킹 서비스로 전송
      // sendErrorToService(error, errorInfo);
    }
  }

  render() {
    if (this.state.hasError) {
      return this.props.fallback || (
        <div className="flex flex-col items-center justify-center min-h-[400px] p-8">
          <div className="text-center max-w-md">
            <h2 className="text-xl font-semibold text-gray-900 mb-4">
              문제가 발생했습니다
            </h2>
```

```typescript
export const useApprovalCounts = () => {
  const [counts, setCounts] = useState({
    pending: 0,
    approved: 0,
    rejected: 0,
    total: 0,
  });
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const fetchCounts = useCallback(async () => {
    try {
      setLoading(true);
      setError(null);
      
      // 병렬로 각 상태별 데이터 요청
      const [pendingRes, approvedRes, rejectedRes] = await Promise.all([
        api.get('/approvals?status=pending'),
        api.get('/approvals?status=approved'),
        api.get('/approvals?status=rejected'),
      ]);

      const newCounts = {
        pending: pendingRes.data.count,
        approved: approvedRes.data.count,
        rejected: rejectedRes.data.count,
        total: pendingRes.data.count + approvedRes.data.count + rejectedRes.data.count,
      };

      setCounts(newCounts);
    } catch (err) {
      setError('승인 개수를 불러오는데 실패했습니다.');
      console.error('Failed to fetch approval counts:', err);
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => {
    fetchCounts();
  }, [fetchCounts]);

  return {
    counts,
    loading,
    error,
    refetch: fetchCounts,
  };
};
```

#### useKeyboardNavigation.ts
```typescript
export const useKeyboardNavigation = (
  items: any[],
  onSelect?: (item: any, index: number) => void
) => {
  const [focusedIndex, setFocusedIndex] = useState(-1);

  const handleKeyDown = useCallback((event: KeyboardEvent) => {
    switch (event.key) {
      case 'ArrowDown':
        event.preventDefault();
        setFocusedIndex((prev) => 
          prev < items.length - 1 ? prev + 1 : 0
        );
        break;
        
      case 'ArrowUp':
        event.preventDefault();
        setFocusedIndex((prev) => 
          prev > 0 ? prev - 1 : items.length - 1
        );
        break;
        
      case 'Enter':
      case ' ':
        event.preventDefault();
        if (focusedIndex >= 0 && onSelect) {
          onSelect(items[focusedIndex], focusedIndex);
        }
        break;
        
      case 'Escape':
        event.preventDefault();
        setFocusedIndex(-1);
        break;
    }
  }, [items, focusedIndex, onSelect]);

  useEffect(() => {
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [handleKeyDown]);

  return {
    focusedIndex,
    setFocusedIndex,
    resetFocus: () => setFocusedIndex(-1),
  };
};
```

## 🚨 트러블슈팅 상세

### 문제: React Hook 규칙 위반

**에러 메시지**:
```
React Hook "useLoadingStore" is called in function "globalLoading" that is neither a React function component nor a custom React Hook
```

**문제 코드**:
```typescript
export const loadingSelectors = {
  globalLoading: () => useLoadingStore((state) => state.globalLoading),
  componentLoading: (key: string) => useLoadingStore((state) => state.loadingStates[key]),
};
```

**분석**:
- 일반 객체의 메서드에서 React Hook을 호출
- Hook은 React 함수 컴포넌트나 커스텀 Hook에서만 호출 가능
- ESLint 규칙 위반으로 컴파일 오류 발생

**해결 과정**:
1. **사용처 확인**: `grep -r "loadingSelectors" src/` → 미사용 확인
2. **코드 제거**: 불필요한 selectors 객체 삭제
3. **Hook 수정**: 직접 상태 접근으로 변경

**최종 해결 코드**:
```typescript
// 기존 커스텀 훅 유지
export const useGlobalLoading = () => useLoadingStore((state) => ({
  loading: state.globalLoading,
  message: state.loadingMessage,
  setLoading: state.setGlobalLoading,
  hasAny: state.hasAnyLoading(),
}));

export const useComponentLoading = (key: string) => useLoadingStore((state) => ({
  loading: state.loadingStates[key] || false, // 직접 접근으로 변경
  setLoading: (loading: boolean) => state.setComponentLoading(key, loading),
}));
```

**교훈**:
- React Hook 규칙 준수의 중요성
- 불필요한 추상화 지양
- ESLint 규칙의 의미 이해
