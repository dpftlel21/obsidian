## 작업 1: 증빙자료 업로드 후 결재선 처리 로직 개선

### 🚨 문제 상황
증빙자료가 이미 업로드되어 있을 때 결재선 버튼을 클릭하면 계속해서 "증빙자료를 업로드하세요" 메시지가 뜨는 문제

### 🔍 문제 분석

**기존 hasEvidence 함수에서 증빙자료 체크와 결재선 체크가 혼재**

```tsx
// 문제가 있던 기존 로직
const hasEvidence = (document) => {
  // 증빙자료 체크
  const evidenceFields = [img1, img2, ...];

  // ❌ 결재선 체크가 여기에 섞여있음
  if (!printAppNm || !printApp) return false;

  return evidenceFields.some(field => /* 증빙자료 존재 체크 */);
}
```

**결과적으로 3가지 케이스에서 문제 발생:**
| 상황 | 기존 동작 | 기대 동작 |
|------|----------|-----------|
| 증빙자료 O + 결재선 O | ❌ 업로드 팝업 | ✅ 결재선 팝업 |
| 증빙자료 O + 결재선 X | ❌ 업로드 팝업 | ✅ 결재선 팝업 (신규 등록) |
| 증빙자료 X | ✅ 업로드 팝업 | ✅ 업로드 팝업 → 결재선 팝업 |

### ✅ 해결 방법

**1. 함수 분리**

```tsx
// ✅ 증빙자료만 체크 (결재선과 분리)
const hasEvidence = (document) => {
  const evidenceFields = [img1, img2, img3, img4, img5, file1, file2, file3, file4, file5];
  return evidenceFields.some(field => {
    const strField = String(field).trim();
    return strField.length > 0 && strField !== 'N' && strField !== 'false';
  });
}

// ✅ 결재선만 체크하는 별도 함수 생성
const hasSignLine = (document) => {
  const printAppNm = document.printAppNm;
  const printApp = document.printApp;
  return printAppNm && printAppNm !== null && printApp && printApp !== null;
}
```

**2. 결재선 버튼 클릭 로직 개선**

```tsx
onSignLineRegister: (item) => {
  // 1. 증빙자료가 있으면 바로 결재선 팝업 (결재선 유무 관계없이)
  if (hasEvidence(item)) {
    signLineManager.openSignLinePopup(item);
    return;
  }

  // 2. 증빙자료가 없으면 업로드 먼저
  if (isWriter(item, empNo)) {
    setPendingSignLineDoc(item); // 업로드 완료 후 결재선 팝업 열림
    openFileUploadForDocument(item);
    showToast('증빙자료를 먼저 업로드해주세요.', 'warning');
  } else {
    showToast('증빙자료가 없습니다. 작성자에게 요청해주세요.', 'warning');
  }
}
```

**3. 관련 로직 전체 리팩토링**
- `isApprovableDocument` 함수에서 분리된 함수들 사용
- 선택 가능 문서 체크 로직에서 분리된 함수들 사용
- 전체 결재 로직에서 분리된 함수들 사용

### ✅ 해결 방법

**1. 공통 훅 생성: useBulkSelectionForVicePresident.ts**

```tsx
const useBulkSelectionForVicePresident = (
  allFilteredData: any[],
  hasEvidence: (item: any) => boolean,
  handleBulkApproval: (rankKey?: string) => void,
  isVicePresident: boolean
) => {
  const handleBulkSelection = useCallback((rankKey?: string) => {
    if (rankKey === '부사장' && isVicePresident) {
      // 부사장은 corpCd !== '600' 문서만 선택
      const docsToSelect = allFilteredData
        .filter(doc => (doc as any).corpCd !== '600')
        .filter(item => hasEvidence(item))

      // 토글 방식 선택 로직
    } else {
      handleBulkApproval(rankKey) // 기존 결재 로직
    }
  }, [allFilteredData, hasEvidence, handleBulkApproval, isVicePresident])

  return { handleBulkSelection }
}
```

## 🛠 핵심 기술 구현

### 1. 관심사 분리 패턴

```tsx
// 증빙자료 체크 (독립적)
const hasEvidence = (document: any): boolean => {
  const evidenceFields = [
    document.img1, document.img2, document.img3, document.img4, document.img5,
    document.file1, document.file2, document.file3, document.file4, document.file5
  ];
  
  return evidenceFields.some(field => {
    const strField = String(field).trim();
    return strField.length > 0 && strField !== 'N' && strField !== 'false';
  });
};

// 결재선 체크 (독립적)
const hasSignLine = (document: any): boolean => {
  const { printAppNm, printApp } = document;
  return printAppNm && printAppNm !== null && printApp && printApp !== null;
};

// 결재 가능 여부 체크 (조합)
const isApprovableDocument = (document: any): boolean => {
  return hasEvidence(document) && hasSignLine(document);
};
```

### 2. 공통 훅 패턴

```tsx
// 권한별 결재 로직 추상화
const useBulkSelectionForVicePresident = (
  allFilteredData: any[],
  hasEvidence: (item: any) => boolean,
  handleBulkApproval: (rankKey?: string) => void,
  isVicePresident: boolean
) => {
  const handleBulkSelection = useCallback((rankKey?: string) => {
    if (rankKey === '부사장' && isVicePresident) {
      // 부사장 전용 로직: corpCd !== '600' 문서만 선택
      const docsToSelect = allFilteredData
        .filter(doc => (doc as any).corpCd !== '600')
        .filter(item => hasEvidence(item));

      // 토글 방식 구현
      const allSelected = docsToSelect.length > 0 && 
        docsToSelect.every(doc => selectedRowKeys.includes(doc.key));

      if (allSelected) {
        // 전체 해제
        setSelectedRowKeys(prev => 
          prev.filter(key => !docsToSelect.some(doc => doc.key === key))
        );
      } else {
        // 전체 선택
        setSelectedRowKeys(prev => [
          ...prev.filter(key => !docsToSelect.some(doc => doc.key === key)),
          ...docsToSelect.map(doc => doc.key)
        ]);
      }
    } else {
      // 기존 결재 로직 실행
      handleBulkApproval(rankKey);
    }
  }, [allFilteredData, hasEvidence, handleBulkApproval, isVicePresident, selectedRowKeys]);

  return { handleBulkSelection };
};
```

### 3. 조건부 렌더링 최적화

