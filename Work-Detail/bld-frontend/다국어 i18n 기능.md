# 다국어 i18n 기능

## 개요
한국어·영어·일본어·중국어(간체)·중국어(번체) 5개 언어를 지원하는 다국어(i18n) 기능을 개발하고, 서비스 전반에 걸쳐 번역을 지속적으로 보강했다. 자동 번역 사전(`i18n/auto`)과 수동 오버라이드(`i18n/overrides`) 구조를 사용한다.

## 주요 구현·변경
- 다국어 기능 및 번역 기능 개발: `index.html` locale 처리, `src/i18n/` 구조 도입.
- 누락 번역 보강: `i18n/auto/en·ja·ko·zh·zh-tw.ts`에 수백 개 문구 추가(예: `aaa7d4a`에서 언어별 130~200줄 규모 추가).
- 외국어 표기 통일: '아점저' → BLDway로 통일(한국어는 유지), 일본어 찜 카드 줄바꿈(`text-wrap: balance`) 정리.
- 모바일 공통 헤더 통일 과정에서 빠진 언어 전환을 `LanguageSwitcher` 재사용으로 복원.
