# 빌드 자동화 및 배포

## 개요
프로젝트 초기에 젠킨스와 GitHub Actions 기반의 빌드 자동화 파이프라인을 구축하고, Docker 기반 배포 환경(Dockerfile·nginx)을 마련했다. 이후 프론트엔드 품질 게이트도 도입했다.

## 주요 구현·변경
- 젠킨스 및 깃액션 빌드: `.github/workflows/deploy.yml`, `Jenkinsfile` 추가 및 반복 테스트로 안정화.
- Docker 배포: 초기 `Dockerfile`·`nginx.conf` 구성 및 docker 설정 수정.
- 품질 게이트: frontend quality gates, ai review feedback 도입(lint 규정 탐색 강화 포함).
