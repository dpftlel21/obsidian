# 현재 위치 기준 코스 재계산

## 개요
코스 결과 화면(/result)에서 사용자의 현재 위치를 기준으로 코스 순서를 다시 계산하고, 원래 순서로 복원할 수 있는 기능을 구현했다. 위치 동의, 6곳 이상 코스에서의 장소 선택, 부분 성공 처리, 5개 언어 문구까지 포함하는 마무리 단계 기능이다.

## 주요 구현·변경
- reorder API·요청 빌더·오류 판별 추가: `api/courses/api.ts`·`queries.ts`·`errors.ts`·`types.ts` 확장.
- 결과 화면 로직: `useCurrentLocationCourseReorder.ts`(+284) 신설, `CourseResultView.tsx` 대폭 확장(+244), `CurrentLocationDialogs`·`CurrentLocationNotice` 컴포넌트 추가, `courseResultRequest`·`useResultPersistence`·`useResultSchedule` 보강.
- 위치 동의 다이얼로그, 6곳 이상 코스의 5곳 선택 다이얼로그, 부산 밖 위치 토스트, 부분 성공 제외 안내 처리.
- 5개 언어(ko·en·ja·zh-tw 등) 문구를 `i18n/overrides`에 추가.
