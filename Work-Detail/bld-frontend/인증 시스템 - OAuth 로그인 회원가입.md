# 인증 시스템 - OAuth 로그인 회원가입

## 개요
카카오/구글 OAuth 소셜 로그인과 자체 로그인·회원가입, 이메일 인증을 포함하는 인증 흐름을 구축했다. 소셜 신규 회원의 약관 동의·가입 연결과 모바일 로그인/로그아웃 흐름까지 이후 단계에서 보강했다.

## 주요 구현·변경
- 카카오 OAuth: `src/api/client.ts` 확장, `src/api/shared/base.ts`, `KakaoCallbackView` 콜백 처리 추가. 관련 계획 문서(kakao-auth-hardening) 반영.
- 로그인·회원가입 기능: `src/api/auth/`(api·queries·types), `src/app/routes.tsx` 라우팅, `LoginView`·`SignupView` 구현.
- 회원가입 이메일 인증: `auth/queries.ts`에 인증 요청/확인 흐름 추가, `SignupView`를 이메일 인증 단계 포함 구조로 개편, 환경변수 정리.
- 소셜 로그인 신규 회원의 동의·가입 흐름 연결, 구글 콜백(`GoogleCallbackView`) 처리.
- 모바일 메인 헤더·사이드바 로그인/로그아웃 및 가입 후 메인 이동 흐름 정비.
