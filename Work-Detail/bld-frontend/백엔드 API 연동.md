# 백엔드 API 연동

## 개요
프론트엔드를 실제 백엔드 API와 연동하고, 백엔드 스펙 변경에 맞춰 파라미터·응답 처리를 지속적으로 반영했다. 체류시간 null 보존, 반려동물 3상태, 혼잡도, 좋아요, 축제 필터 등 도메인 데이터의 연동 정합성을 확보하는 단계다.

## 주요 구현·변경
- API 연동 기반 정비 및 백엔드 api 기반 수정사항 반영, 백엔드 수정사항(파라미터·응답) 반영.
- 데이터 연동 정합성: 체류시간 null 보존, 반려동물 3상태(`api/places/petStatus.ts`), 혼잡도(`queries.congestion.test.tsx`), 좋아요·축제 필터 연동. `api/courses/queries.ts`·`api/places/`(api·queries·types) 확장 및 테스트 보강.
- 관련 문서(frontend-action-checklist, backend-api-changes) 정리 및 성능(lighthouse) 대응.
