# 혼잡도 계산 및 추천 근거

## 개요
장소 혼잡도 계산 기능을 추가하고, 코스 추천 결과에 대한 추천 근거를 사용자에게 설명하는 기능을 구현·개선했다. 혼잡도 표기의 다국어 처리와 추천 근거 정합성도 함께 다뤘다.

## 주요 구현·변경
- 혼잡도 계산 추가: `api/admin/api.test.ts` 등 테스트 포함, 관련 문서(contest-judge-evaluation) 정리.
- 혼잡도 및 코스 추천 관련 팝업 수정, 추천 근거 정합성과 혼잡도 다국어 개선.
- 추천 근거 모달 가독성 개선: 접이식 참고 섹션, 타이포그래피, 펼침 애니메이션 적용.
- 이후 혼잡도는 `api/places/queries.congestion.test.tsx` 등으로 백엔드 연동·검증(관련: 백엔드 API 연동).
