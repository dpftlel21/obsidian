# 관광 데이터 조회 및 장소 검색

## 개요
관광 데이터를 조회해 리스트로 제공하고, 장소 검색·인기 코스·장소 상세보기 화면을 개발했다. 검색 View는 프로젝트 전반에서 지속적으로 커진 핵심 화면이다.

## 주요 구현·변경
- 관광 데이터 API: `src/api/tourism/`(api·queries·types) 신규 구성, `SearchView.tsx`에 조회 결과 리스트 반영(대규모 변경).
- 인기코스 및 장소 검색 UI 개발, 장소 상세보기 화면 정비.
- 검색 결과 상단 타이틀·검색 카드 UI 개선, 배경 처리를 festival 기준으로 통일.
- 검색 입력 포커스 강조 제거 등 검색 인터랙션 다듬기.
