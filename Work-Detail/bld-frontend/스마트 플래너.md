# 스마트 플래너

## 개요
사용자 취향(테마·이동수단 등)을 입력받아 코스를 자동 생성하는 스마트 플래너 기능을 구현하고, 코스 생성 화면을 개발했다. 이후 취향 초기값 반영과 부산 구·군 전체 제공 등으로 보강됐다.

## 주요 구현·변경
- 스마트 플래너 및 코스 생성 화면: `SmartCoursePlanner`, `CourseCreateView`, `DeparturePlacePicker` 구현 및 코스 생성 페이지 UI 정비.
- 로그인 사용자의 저장 취향(테마·이동수단)을 스마트 플래너 초기값에 반영(비로그인·미저장 기본값 유지, 사용자 선행 조작 보존, 지원 테마만 필터).
- 스마트 플래너에 부산 16개 구·군 전체 제공(공통 상수 `BUSAN_DISTRICTS` 사용).
- `SmartCoursePlanner.test.tsx`·`CourseCreateView.test.tsx` 회귀 테스트 확보.
