# 모바일 반응형 UI 및 공통 헤더 통일

## 개요
서비스 전반의 반응형 대응과 모바일 UX를 집중적으로 개선했다. 라우트 전용 CSS를 Tailwind로 이관하고, 데스크톱/모바일 공통 헤더를 통일하며 모바일 홈·결과·검색 내비게이션을 정비했다.

## 주요 구현·변경
- 라우트 전용 CSS를 Tailwind로 이관해 스타일 체계 통일.
- 모바일 UI 개선: 공통 헤더 통일, 결과 일정 바 재배치, 모바일 코스 결과 스크롤 및 검색 내비게이션 정비.
- 모바일 홈 목록·헤더와 추천 근거 팝업 UX 개선, 좁은 화면 장소명 가독성 개선.
- 반응형·페이지별 QA 및 UI/UX 점검 결과 정리.
