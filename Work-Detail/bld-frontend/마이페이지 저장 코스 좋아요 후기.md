# 마이페이지 저장 코스 좋아요 후기

## 개요
마이페이지를 중심으로 저장 코스, 좋아요(찜), 여행선 보관, 후기 작성 등 사용자 개인화 기능을 개발·정비했다. 여행 취향 패널과 반려동물/마커 표시 등 상세 UX도 다듬었다.

## 주요 구현·변경
- 마이페이지 UI/UX 및 장소검색 지도 바인딩 수정, 인기 코스·마이페이지 저장 코스 grid 레이아웃 정비.
- 후기 작성 파일 업로드 기능 추가.
- 좋아요·여행선 보관 상태 정합성 확보 및 코스 상세 액션 정리.
- 마이페이지·장소·축제 UX 개선과 반려동물/마커 표시 정리, 여행 취향 패널 좌측 정렬.
