### 📝 문제 설명
> [!bug] **What happened?**
> 
> **현상**: 
> - 줌 인/아웃 버튼을 빠르게 연속으로 클릭하면 줌 레벨이 예상과 다르게 변경됨
> - 줌 레벨이 최대값(200%)을 초과하거나 최소값(50%) 미만으로 내려가는 경우 발생
> - 화면에 표시되는 줌 퍼센트와 실제 적용된 줌 레벨이 불일치
> - 줌 리셋 버튼 클릭 시 100%로 돌아가지 않고 이전 값이 유지되는 경우 발생
> - 연속 클릭 시 UI가 일시적으로 멈추는 현상
> 
> **발생 시점**: 
> - 사용자가 줌 버튼을 빠르게 여러 번 클릭할 때
> - 특히 최대/최소 범위 근처에서 클릭할 때
> - 문서 뷰어, 이미지 뷰어 등 줌 기능이 있는 모든 페이지
> 
> **영향 범위**:
> - EMK Frontend의 모든 줌 컨트롤 컴포넌트
> - 문서 뷰어, 이미지 뷰어, PDF 뷰어 등

## 🔬 근본 원인 분석 (Root Cause Analysis)

### 📊 5 Whys 분석
1. **Why 1**: 왜 이 문제가 발생했나?
   - 답: 줌 레벨 상태 업데이트가 비동기적으로 처리되어 연속 클릭 시 이전 상태를 참조하기 때문

2. **Why 2**: 왜 이전 상태를 참조하게 되나?
   - 답: setState의 일반적인 호출 방식을 사용하여 클로저 문제가 발생하기 때문

3. **Why 3**: 왜 클로저 문제가 발생하나?
   - 답: 이벤트 핸들러 함수가 생성될 때의 상태값을 캡처하여 사용하기 때문

4. **Why 4**: 왜 범위 제한이 작동하지 않나?
   - 답: 상태 업데이트 전에 범위 체크를 하여 비동기 업데이트 시 무효화되기 때문

5. **Why 5**: 왜 함수형 업데이트를 사용하지 않았나?
   - 답: 초기 개발 시 단순한 상태 업데이트만 고려하고 연속 클릭 시나리오를 고려하지 않았기 때문

### 🎯 근본 원인
> [!important] **Root Cause**
> 
> **주원인**: React 상태 업데이트의 비동기 특성 + 일반적인 setState 사용으로 인한 클로저 문제
> 
> **세부 원인들**:
> 1. setState에서 함수형 업데이트 미사용 (이전 상태 기반 업데이트 불가)
> 2. 연속 클릭 방지 로직 부재 (디바운싱/쓰로틀링 미적용)
> 3. 범위 체크가 상태 업데이트 외부에서 수행됨
> 4. useCallback 미사용으로 함수 재생성 및 클로저 문제 발생
> 5. 줌 진행 중 상태 표시 부재

## 💡 해결 방안 (Solutions)

### 🚀 임시 해결책 (Workaround)
> [!tip] **Immediate Fix**
> **방법**: 버튼 클릭 후 일정 시간 동안 버튼 비활성화
> 
> **단계**:
> 1. 버튼 클릭 시 disabled 상태로 변경
> 2. 300ms 후 다시 활성화
> 3. 사용자에게 천천히 클릭하도록 안내
> 
> **제한사항**: 
> - 사용자 경험 저하 (빠른 조작 불가)
> - 근본적인 상태 동기화 문제 미해결
> - 여전히 범위 초과 가능성 존재

### 🔧 근본적 해결책 (Long-term Fix)
> [!success] **Permanent Solution**
> **방법**: 함수형 상태 업데이트 + useCallback + 디바운싱 적용
> 
> **구현 계획**:
> - [x] 1단계: setState를 함수형 업데이트로 변경 🗓️ 2026-01-26
> - [x] 2단계: useCallback으로 함수 메모이제이션 🗓️ 2026-01-26
> - [x] 3단계: 줌 진행 중 상태 추가 및 디바운싱 🗓️ 2026-01-26
> - [x] 검증: 연속 클릭 시나리오 테스트 🗓️ 2026-01-26
> 
> **구체적 구현**:
> ```typescript
> // Before (문제 코드)
> const [zoomLevel, setZoomLevel] = useState(100);
> 
> const zoomIn = () => {
>   if (zoomLevel < 200) {
>     setZoomLevel(zoomLevel + 10); // 클로저 문제 발생
>   }
> };
> 
> const zoomOut = () => {
>   if (zoomLevel > 50) {
>     setZoomLevel(zoomLevel - 10); // 클로저 문제 발생
>   }
> };
> 
> const resetZoom = () => {
>   setZoomLevel(100); // 간단하지만 상태 동기화 문제 가능
> };
> 
> // After (해결 코드)
> const useZoom = (initialZoom: number = 100) => {
>   const [zoomLevel, setZoomLevel] = useState(initialZoom);
>   const [isZooming, setIsZooming] = useState(false);
>   
>   const zoomIn = useCallback(() => {
>     setIsZooming(true);
>     setZoomLevel(prev => {
>       // 함수형 업데이트로 최신 상태 보장
>       const newZoom = Math.min(prev + 10, 200); // 범위 제한
>       return newZoom;
>     });
>     // 디바운싱: 300ms 후 다시 활성화
>     setTimeout(() => setIsZooming(false), 300);
>   }, []);
>   
>   const zoomOut = useCallback(() => {
>     setIsZooming(true);
>     setZoomLevel(prev => {
>       const newZoom = Math.max(prev - 10, 50); // 범위 제한
>       return newZoom;
>     });
>     setTimeout(() => setIsZooming(false), 300);
>   }, []);
>   
>   const resetZoom = useCallback(() => {
>     setIsZooming(true);
>     setZoomLevel(100);
>     setTimeout(() => setIsZooming(false), 300);
>   }, []);
>   
>   return { zoomLevel, isZooming, zoomIn, zoomOut, resetZoom };
> };
> 
> // 컴포넌트에서 사용
> const ZoomControl: React.FC = () => {
>   const { zoomLevel, isZooming, zoomIn, zoomOut, resetZoom } = useZoom();
>   
>   return (
>     <div className="zoom-control">
>       <button 
>         onClick={zoomOut} 
>         disabled={isZooming || zoomLevel <= 50}
>         aria-label="Zoom out"
>       >
>         -
>       </button>
>       <span className="zoom-level">{zoomLevel}%</span>
>       <button 
>         onClick={zoomIn} 
>         disabled={isZooming || zoomLevel >= 200}
>         aria-label="Zoom in"
>       >
>         +
>       </button>
>       <button 
>         onClick={resetZoom} 
>         disabled={isZooming}
>         aria-label="Reset zoom"
>       >
>         Reset
>       </button>
>     </div>
>   );
> };
> ```
> 
> **필요 리소스**: 
> - 개발 시간: 2시간
> - 테스트 시간: 30분
> - 코드 리뷰: 30분
