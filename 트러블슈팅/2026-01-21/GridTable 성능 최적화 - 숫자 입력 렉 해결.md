### 📝 문제 설명
> [!bug] **What happened?**
> 
> **현상**: 
> - GridTable에서 숫자를 입력할 때마다 300ms의 지연 발생
> - 타이핑할 때마다 UI가 얼어붙는 듯한 현상
> - CPU 사용률이 85%까지 급증
> - 메모리 사용량도 45MB까지 증가
> 
> **발생 시점**: 
> - 사용자가 숫자 입력 필드에 타이핑할 때마다
> - 특히 긴 숫자를 입력하거나 여러 셀을 연속으로 편집할 때 심화
> 
> **영향 범위**:
> - EMK Frontend의 모든 GridTable 컴포넌트
> - 특히 DeliveryNote와 OrderStatus 페이지에서 심각

## 🔬 근본 원인 분석 (Root Cause Analysis)

### 📊 5 Whys 분석
1. **Why 1**: 왜 이 문제가 발생했나?
   - 답: 숫자 입력 시마다 실시간 콤마 포맷팅이 실행되기 때문

2. **Why 2**: 왜 실시간 포맷팅이 성능 문제를 일으키나?
   - 답: 매 키 입력마다 전체 컴포넌트가 리렌더링되고 복잡한 계산이 실행되기 때문

3. **Why 3**: 왜 전체 컴포넌트가 리렌더링되나?
   - 답: 상태 업데이트가 상위 컴포넌트까지 전파되면서 하위 컴포넌트들도 모두 재렌더링되기 때문

4. **Why 4**: 왜 상태 업데이트가 과도하게 전파되나?
   - 답: 데이터 저장과 UI 표시 로직이 결합되어 있고, 메모이제이션이 적용되지 않았기 때문

5. **Why 5**: 왜 처음부터 성능 최적화가 고려되지 않았나?
   - 답: 초기 개발 시 소량의 데이터만 고려했고, 실시간 피드백을 우선시했기 때문

### 🎯 근본 원인
> [!important] **Root Cause**
> 
> **주원인**: 데이터 저장과 UI 표시 로직의 결합 + 실시간 포맷팅으로 인한 과도한 렌더링
> 
> **세부 원인들**:
> 1. 매 키 입력마다 `formatNumberWithCommas()` 함수 실행
> 2. 포맷팅 결과가 상태에 저장되면서 연쇄적 리렌더링 발생
> 3. React.memo, useMemo 등 최적화 기법 미적용
> 4. 불필요한 의존성 배열로 인한 과도한 useEffect 실행

## 💡 해결 방안 (Solutions)

### 🚀 임시 해결책 (Workaround)
> [!tip] **Immediate Fix**
> **방법**: 실시간 포맷팅을 비활성화하고 onBlur 시점에만 포맷 적용
> 
> **단계**:
> 1. `handleEditChange` 함수에서 포맷팅 로직 제거
> 2. 원시 값만 상태에 저장
> 3. onBlur 이벤트에서만 포맷팅 실행
> 
> **제한사항**: 
> - 타이핑 중에는 콤마가 표시되지 않아 UX가 다소 저하
> - 근본적인 아키텍처 문제는 해결되지 않음

### 🔧 근본적 해결책 (Long-term Fix)
> [!success] **Permanent Solution**
> **방법**: 데이터 저장과 UI 표시 로직 완전 분리 + React 최적화 기법 적용
> 
> **구현 계획**:
> - [x] 1단계: 포맷팅 로직 분리 및 지연 로딩 적용 🗓️ 2026-01-21
> - [x] 2단계: React.memo, useMemo 적용 🗓️ 2026-01-21
> - [x] 3단계: 상태 업데이트 최적화 🗓️ 2026-01-21
> - [x] 검증: 성능 테스트 및 사용자 테스트 🗓️ 2026-01-21
> 
> **구체적 구현**:
> ```typescript
> // Before (문제 코드)
> const handleEditChange = (rowIndex: number, field: string, value: any) => {
>   const formattedValue = formatNumberWithCommas(value); // 매번 실행
>   updateCellData(rowIndex, field, formattedValue);
>   triggerRerender(); // 과도한 렌더링
> };
> 
> // After (해결 코드)
> const submitEdit = (rowIndex: number, field: string, value: any) => {
>   updateCellData(rowIndex, field, value); // 원시값만 저장
>   onCellEdit?.(rowIndex, field, value);
> };
> 
> const formatForDisplay = useMemo(() => (value: any) => {
>   if (value === undefined || value === null || value === '') return '-';
>   return typeof value === 'number' ? value.toLocaleString() : value;
> }, []);
> 
> // 컴포넌트 메모이제이션
> const CellComponent = React.memo(({ value, ...props }) => {
>   return <div>{formatForDisplay(value)}</div>;
> });
> ```
> 
> **필요 리소스**: 
> - 개발 시간: 4시간
> - 테스트 시간: 1시간
> - 성능 검증: 30분
