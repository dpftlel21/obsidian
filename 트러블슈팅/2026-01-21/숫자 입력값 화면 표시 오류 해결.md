## 🔬 근본 원인 분석 (Root Cause Analysis)

### 📊 5 Whys 분석
1. **Why 1**: 왜 입력값이 화면에 표시되지 않나?
   - 답: 숫자 0을 falsy 값으로 처리하여 '-'로 표시하고, API 데이터로 사용자 입력을 덮어쓰기 때문

2. **Why 2**: 왜 0을 falsy로 처리하게 되었나?
   - 답: 빈 값과 0을 구분하지 않고 동일하게 처리하는 조건문을 사용했기 때문

3. **Why 3**: 왜 API 데이터가 사용자 입력을 덮어쓰나?
   - 답: useEffect의 의존성 배열에 사용자 입력 상태가 포함되어 있어서 입력할 때마다 API 데이터로 리셋되기 때문

4. **Why 4**: 왜 의존성 배열에 사용자 입력이 포함되었나?
   - 답: 상태 동기화 로직이 명확하지 않아서 모든 관련 상태를 의존성에 포함했기 때문

5. **Why 5**: 왜 처음부터 상태 관리 설계가 명확하지 않았나?
   - 답: API 데이터와 사용자 입력 데이터의 우선순위와 병합 규칙을 명확히 정의하지 않았기 때문

### 🎯 근본 원인
> [!important] **Root Cause**
> 
> **주원인**: 숫자 0에 대한 잘못된 falsy 처리 + API 데이터와 사용자 입력 간의 상태 동기화 문제
> 
> **세부 원인들**:
> 1. `renderCellContent`에서 0 값을 빈 값으로 처리
> 2. useEffect 의존성 배열에 userInputs 포함으로 인한 무한 루프
> 3. API 데이터 업데이트 시 사용자 입력값 보존 로직 부재
> 4. 데이터 소스별 우선순위 규칙 미정의

## 💡 해결 방안 (Solutions)

### 🚀 임시 해결책 (Workaround)
> [!tip] **Immediate Fix**
> **방법**: 0 값 표시 조건 수정 및 useEffect 의존성 배열 임시 제거
> 
> **단계**:
> 1. renderCellContent에서 0 값 표시 조건 수정
> ```typescript
> // 임시 수정
> if (formatted !== undefined && formatted !== null) {
>   return formatted;
> }
> ```
> 2. useEffect 의존성 배열에서 userInputs 제거
> 3. 수동 상태 동기화 로직 추가
> 
> **제한사항**: 
> - 근본적인 상태 관리 문제는 해결되지 않음
> - 다른 edge case에서 문제 발생 가능성

### 🔧 근본적 해결책 (Long-term Fix)
> [!success] **Permanent Solution**
> **방법**: 타입 안전한 조건 처리 + 명확한 상태 동기화 로직 구현
> 
> **구현 계획**:
> - [x] 1단계: 숫자 0과 빈 값 구분 처리 🗓️ 2026-01-21
> - [x] 2단계: 사용자 입력 보존 로직 구현 🗓️ 2026-01-21
> - [x] 3단계: 의존성 배열 최적화 🗓️ 2026-01-21
> - [x] 검증: 다양한 시나리오 테스트 🗓️ 2026-01-21
> 
> **구체적 구현**:
> ```typescript
> // Before (문제 코드)
> const renderCellContent = (value: any) => {
>   const formatted = formatValue(value);
>   if (formatted !== undefined && formatted !== null) { // 0이 falsy로 처리됨
>     return formatted;
>   }
>   return '-';
> };
> 
> useEffect(() => {
>   if (orderData) {
>     // 사용자 입력값을 무조건 덮어씀
>     setItems(orderData.map(item => ({ ...item, inQty: 0 })));
>   }
> }, [orderData, userInputs]); // 잘못된 의존성
> 
> // After (해결 코드)
> const renderCellContent = (value: any) => {
>   const formatted = formatValue(value);
>   // 빈 문자열도 체크하여 0 값 정상 표시
>   if (formatted !== undefined && formatted !== null && formatted !== '') {
>     return formatted;
>   }
>   return '-';
> };
> 
> useEffect(() => {
>   if (orderData && !hasUserInputs) {
>     // 사용자 입력이 없을 때만 초기화
>     setItems(processApiData(orderData));
>   }
> }, [orderData]); // 의존성 배열 최적화
> 
> // 사용자 입력 보존 로직
> const preserveUserInputs = (newData: any[], currentData: any[]) => {
>   return newData.map(newItem => {
>     const existing = currentData.find(item => item.id === newItem.id);
>     // 기존 사용자 입력값이 있으면 보존
>     return existing?.inQty ? { ...newItem, inQty: existing.inQty } : newItem;
>   });
> };
> 
> // 상태 병합 로직
> const mergeApiAndUserData = (apiData: any[], userData: Map<string, any>) => {
>   return apiData.map(item => ({
>     ...item,
>     // 사용자 입력이 있으면 사용자 입력 우선, 없으면 API 데이터 사용
>     inQty: userData.has(item.id) ? userData.get(item.id).inQty : item.inQty
>   }));
> };
> ```
>

> - 개발 시간: 2시간
> - 테스트 시간: 1시간
> - 코드 리뷰: 30분
