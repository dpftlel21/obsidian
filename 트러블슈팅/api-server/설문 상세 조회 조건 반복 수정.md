# 설문 상세 조회 조건 반복 수정

## 문제
승무팀장 평가 설문의 상세(detail) 조회 API가 의도한 결과를 반환하지 못해, 같은 날(2026-07-10) 조회 조건을 여러 차례 반복 수정했다. 설문 저장 시에도 완료 여부가 반영되지 않는 문제가 있었다.

## 원인
- 설문 detail 조회 쿼리의 조건절(where)이 대상 데이터를 정확히 필터링하지 못했다.
- 설문 저장 조건에 완료 여부 플래그(`FIN_YN`)가 빠져 있었다.

## 해결
- `f3f4531` → `b9e8bb6` → `a4dd963` → `b6b0758`: 설문 detail 조회 조건을 반복적으로 조정하며 올바른 결과가 나오도록 수정.
- `387cb22`: 설문 저장 조건에 `FIN_YN`을 포함하도록 보정.

## 교훈
동일 조건을 짧은 간격으로 여러 번 수정한 이력이 남았다. 조회 조건 변경은 실제 데이터 케이스로 먼저 검증한 뒤 반영하는 편이 반복 커밋을 줄인다.

## 관련 커밋
- `2026-07-10` `387cb22` 설문 저장하기 조건 수정 FIN_YN 포함
- `2026-07-10` `b6b0758` 설문 detail api 조건 수정.
- `2026-07-10` `a4dd963` 설문 detail api 조건 수정
- `2026-07-10` `b9e8bb6` 설문 detail api 조건 수정.
- `2026-07-10` `f3f4531` 설문 detail api 조건 수정
