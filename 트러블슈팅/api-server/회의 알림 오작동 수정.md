# 회의 알림 오작동 수정

## 문제
알림 기능 초기 구현 이후 알림이 정상적으로 발송·처리되지 않는 오류가 있었고, 특히 회의가 재수정(재편성)될 때 알림이 올바르게 나가지 않았다.

## 원인
- 알림 발송/읽음 처리 흐름에 예외 케이스가 남아 있었다.
- 회의 일정 변경 시 알림을 재발행하는 경로가 `service.py`와 `notification_service.py` 사이에서 제대로 연결되지 않았다.

## 해결
- `42691c0`: 알림 기능 동작 오류를 보정.
- `347ab59`: 재수정 회의 상황에서 알림이 나가도록 `notification_service.py`(+39)와 `service.py`(+19)를 수정.

## 관련 커밋
- `2026-07-23` `347ab59` 재수정 회의 알림 기능 수정
- `2026-07-20` `42691c0` 알림기능 수정
