# 테이블 체크박스 렌더링·단일선택 오류

## 문제
그리드 테이블의 행 선택 체크박스가 제대로 렌더링되지 않거나, 단일 선택이어야 하는 화면(임시저장이력 등)에서 체크 상태가 어긋나는 오류가 있었다. 납품서 체크에서도 체크 오류가 발생했다.

## 원인
공통 그리드(`GridTable`, `GridSearchForm`)의 체크박스 상태가 행 데이터 갱신·리렌더와 동기화되지 않아, 체크 상태가 이전 렌더에 남거나 다중/단일 선택 규칙이 일관되게 적용되지 않았다.

## 해결
- `GridTable.tsx`·`GridSearchForm.tsx`의 체크박스 상태 관리 로직을 대폭 정리(총 300라인 이상 변경)하여 렌더 동기화 문제를 해결했다.
- 임시저장이력 등에서 체크박스 단일 선택(`ca3b343`)을 명시적으로 강제하고, 납품서 체크 오류(`0b23cdc`)를 함께 수정했다.

## 관련 파일
- `frontend/src/common/grid/GridTable.tsx`, `GridSearchForm.tsx`
- `frontend/src/components/order/DeliveryPopup.tsx`, `frontend/src/components/orderReg/FreqOrderReg.tsx`
