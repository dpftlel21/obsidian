# 납품서 날짜 재조회 안 되는 문제

## 문제
납품서 조회 화면에서 날짜를 선택해 조회한 뒤, 같은 조건(또는 날짜만 변경)으로 다시 조회하면 목록이 갱신되지 않는 문제가 있었다.

## 원인
조회 트리거가 검색 조건(날짜) 변화에만 의존하도록 되어 있어, 동일 조건 재조회나 특정 날짜 재선택 시 상태 변화가 감지되지 않아 재요청이 일어나지 않았다.

## 해결
- `DeliveryNote.tsx`(17라인 추가/조정)에서 조회 실행 로직을 조건 변화가 아닌 명시적 조회 액션 기준으로 보정하여, 날짜 재선택 시에도 항상 재조회되도록 했다.

## 관련 파일
- `frontend/src/components/vendor/order/DeliveryNote.tsx`
