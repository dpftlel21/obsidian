# 다국어 번역 오류 수정

## 문제
용어사전 기반 번역 전환 이후, 일부 화면(차량 접수/검사, 테이블 헤더 등)에서 번역이 누락되거나 잘못 표시되는 오류가 있었다. 중어/영문 alert 문구도 정비가 필요했다.

## 원인
자체 번역 유틸리티(`glossaryTranslator`) 적용 범위가 일부 동적 텍스트(차량 검사 테이블, 헤더)까지 완전히 커버하지 못했고, 특정 컴포넌트에서 번역 훅 연결이 빠져 있었다.

## 해결
- `GoogleTranslator.tsx`(88라인)와 차량 접수/검사 컴포넌트(`CarLogin`, `CarRegister`, `InspectionTable` 159라인)의 번역 연결을 보강했다(`8c91a09`).
- 테이블 헤더를 번역 대상으로 포함(`f0eea17`)하고, 중어 컬럼/영문 alert 문구(`4ccf126`)를 정리했다.

## 관련 파일
- `frontend/src/common/header/GoogleTranslator.tsx`
- `frontend/src/components/test/imageUpload/CarRegister.tsx`, `InspectionTable.tsx`, `CarLogin.tsx`
