# 납품현황 렌더링 오류 수정

## 문제
납품현황 화면에서 렌더링 오류가 발생했다. 조회 결과와 팝업, 주문등록 폼이 함께 갱신될 때 화면이 정상적으로 그려지지 않았다.

## 원인
`DeliveryStatus`, `OrderPopup`, `FreqOrderReg` 세 컴포넌트가 상태를 공유/전파하는 과정에서, 조건부 렌더와 데이터 준비 시점이 어긋나 렌더 오류가 났다.

## 해결
- `DeliveryStatus.tsx`(25라인)·`OrderPopup.tsx`(25라인)·`FreqOrderReg.tsx`(70라인)의 렌더 조건과 데이터 바인딩 시점을 정리하여 오류를 제거했다.
- 팝업 열림/닫힘과 목록 갱신의 순서를 명확히 하여 재현을 차단했다.

## 관련 파일
- `frontend/src/components/order/DeliveryStatus.tsx`, `OrderPopup.tsx`
- `frontend/src/components/orderReg/FreqOrderReg.tsx`
