# 세션 사용자활동 감지 시간 조정

## 문제
세션 타이머의 사용자 활동 감지 주기가 10초로 설정되어 있어, 짧은 주기로 활동을 감지·초기화하면서 불필요한 처리가 잦고 실사용 패턴과 맞지 않았다.

## 원인
`SessionTimer.tsx`의 활동 감지 인터벌이 10초로 하드코딩되어 있었다. 사용자가 잠시 화면을 읽는 정도의 짧은 비활동에도 민감하게 반응했다.

## 해결
- `SessionTimer.tsx`(2라인 수정)에서 활동 감지 시간을 10초에서 2분으로 변경하여, 실제 사용 흐름에 맞게 세션 유지/만료 판정 주기를 조정했다.

## 관련 파일
- `frontend/src/common/header/SessionTimer.tsx`
