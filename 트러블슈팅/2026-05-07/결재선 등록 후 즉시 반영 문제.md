# 결재선 등록 후 즉시 반영 문제

## 문제 개요
- **발생 기간**: 2026년 3월 - 4월
- **심각도**: ⭐⭐⭐⭐ (높음)
- **영향도**: 사용자 워크플로우 중단

## 문제 현상

### 증상
```javascript
// 문제: 결재선 등록 후 화면에 바로 반영 안됨
const handleSignLineSave = async () => {
  await signLineApi.saveInterviewSignLine(params)
  // 여기서 상태 업데이트가 안됨 - 화면에 반영 X
}
```

### 구체적 현상
1. 결재선 등록 완료 후 버튼 클릭
2. API 호출은 성공하지만 화면에 즉시 반영되지 않음
3. 페이지 새로고침해야만 결과 확인 가능
4. 사용자가 등록 성공 여부를 바로 알 수 없음

## 원인 분석

### 1차 원인: 상태 동기화 누락
- React 상태와 서버 상태 간 동기화 부재
- API 성공 후 로컬 상태 업데이트 로직 누락

### 2차 원인: 리액트 쿼리 캐시 무효화 누락
- 서버 데이터 변경 후 캐시 업데이트 안함
- 기존 캐시된 데이터가 계속 표시됨

## 해결 과정

### 1단계: 실시간 상태 동기화 (3월 말)
```javascript
const signLineManager = useSignLineManager({
  onSuccess: () => {
    // 결재선 등록 성공시 즉시 pendingSignLines 업데이트
    setPendingSignLinesCount(prev => prev + 1)
    
    // React Query 캐시 무효화
    queryClient.invalidateQueries(['signLines'])
    queryClient.invalidateQueries(['pendingApprovals'])
  }
})
```

### 2단계: 결재선 확정 + 자동결재 연계 (4월)
```javascript
const applySignLinesWithAutoApproval = useCallback(async () => {
  try {
    // 1. 먼저 결재선 확정
    await signLineManager.applySignLines()
    
    // 2. 상태 즉시 업데이트
    setPendingSignLinesCount(0)
    
    // 3. 그 다음에 자동결재 실행
    for (const key of keys) {
      const myApprover = line.approvers?.find((a: any) => a.empNo === empNo)
      if (myApprover) {
        const approvalParams = {
          voucherNo: key,
          empNo,
          approvalType: 'AUTO'
        }
        await approvalSignMutation.mutateAsync(approvalParams)
      }
    }
    
    // 4. 최종 상태 동기화
    await queryClient.invalidateQueries(['approvalStatus'])
    
    // 5. 페이지 새로고침으로 최신 상태 반영 (임시)
    setTimeout(() => {
      window.location.reload()
    }, 100)
  } catch (error) {
    console.error('Auto approval failed:', error)
    showToast('자동 결재 중 오류가 발생했습니다.', 'error')
  }
}, [])
```

### 3단계: 최적화 및 사용자 피드백 개선
```javascript
const [isProcessing, setIsProcessing] = useState(false)

const handleSignLineProcess = async () => {
  setIsProcessing(true)
  
  try {
    // 진행상황 토스트
    showToast('결재선을 등록하고 있습니다...', 'info')
    
    await applySignLinesWithAutoApproval()
    
    // 성공 토스트
    showToast('결재선 등록 및 자동결재가 완료되었습니다.', 'success')
    
  } catch (error) {
    showToast('처리 중 오류가 발생했습니다.', 'error')
  } finally {
    setIsProcessing(false)
  }
}
```

## 해결 결과

### 성과
- ✅ 결재선 등록 → 확정 → 자동결재 연속 처리
- ✅ 사용자 클릭 1회로 전체 프로세스 완료
- ✅ 실시간 상태 피드백
