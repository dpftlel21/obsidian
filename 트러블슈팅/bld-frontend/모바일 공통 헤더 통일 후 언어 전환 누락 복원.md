# 모바일 공통 헤더 통일 후 언어 전환 누락 복원

## 배경
공통 헤더 통일 작업(`47cb0fd`) 과정에서 모바일 햄버거 메뉴의 언어 전환이 사라진 회귀를 `963b3fc`(2026-09-21)에서 복원했다.

## 증상
모바일 사용자가 햄버거 메뉴를 열어도 **언어 전환 UI가 없어** 언어를 바꿀 수 없었다.

## 원인
헤더를 공통 컴포넌트로 통합하면서 데스크톱에만 있던 `LanguageSwitcher`가 모바일 내비게이션 패널(`MobileNavigation`)에 반영되지 않았다.

## 해결
데스크톱과 **동일한 `LanguageSwitcher` 컴포넌트를 재사용**해 햄버거 패널에 언어 선택 영역을 추가했다.
```tsx
// src/components/shared/MobileNavigation.tsx
import LanguageSwitcher from './LanguageSwitcher';
// ...
<div className="mobile-navigation__lang">
  <span className="mobile-navigation__lang-label">{t('language.select')}</span>
  <LanguageSwitcher />
</div>
```
관련 스타일은 `src/index.css`에 보강.

## 비고
데스크톱과 같은 컴포넌트를 재사용하므로 언어 상태·전환 로직이 단일 소스로 유지된다(중복 구현 없음).

## 관련 커밋
- `2026-09-21` `963b3fc` 모바일 햄버거 메뉴에 언어 전환 복원
