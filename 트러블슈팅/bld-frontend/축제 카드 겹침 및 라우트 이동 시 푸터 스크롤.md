# 축제 카드 겹침 및 라우트 이동 시 푸터 스크롤

## 배경
심사/QA 중 발견된 화면 결함 묶음. `f09c6f0`(2026-09-28)에서 모바일 축제 히어로 카드 겹침과 라우트 이동 시 스크롤 위치 문제를 함께 수정했다.

## 증상
1. 모바일 축제 히어로 카드에서 **날짜 배지와 2줄 제목이 겹쳐** 보임.
2. 푸터 링크로 페이지를 이동하면 **새 페이지가 이전 스크롤 위치(중간)에서 시작**됨.

## 원인
1. 날짜 배지의 모바일 위치(`max-[767px]:bottom-[10.875rem]`)가 2줄 제목 영역과 겹치는 좌표였다.
2. 라우트 전환 시 문서 스크롤을 상단으로 되돌리는 처리가 없어 이전 스크롤 위치가 그대로 남았다.

## 해결
### 1) 날짜 배지 위치 상향 (겹침 제거)
```diff
- max-[767px]:bottom-[10.875rem]
+ max-[767px]:bottom-[13.5rem]
```
(`src/components/festival/FestivalView.tsx`의 `FeaturedFestival` 배지)

### 2) 라우트 변경 시 상단 스크롤 (ScrollToTop)
```tsx
// src/app/routes.tsx
/** 라우트(pathname)가 바뀌면 문서 스크롤을 맨 위로 되돌린다. */
function ScrollToTop() {
  const { pathname } = useLocation();
  useEffect(() => {
    window.scrollTo({ top: 0, left: 0, behavior: 'auto' });
  }, [pathname]);
  return null;
}
// 라우터 트리에 <ScrollToTop /> 삽입
```

## 비고
같은 커밋에서 외국어 브랜드명('아점저' → **BLDway**) 통일과 일본어 찜 카드 줄바꿈(`text-wrap: balance`)도 함께 처리했다.
