# 브라우저 종료 후 방장·참가자 권한 유지 문제 해결

## 문제
회의 중 방장이나 참가자가 브라우저를 닫았다가 다시 들어오면 권한(방장/참가자)이 유지되지 않았다. 방장이 재접속해도 방장 권한을 잃거나, 승인받았던 참가자가 다시 로비 대기 상태로 돌아가는 증상이 있었다.

## 원인
로비/입장 상태가 세션 기준으로만 관리되어, 브라우저 종료로 세션이 끊기면 이전에 확정된 권한과 승인 이력이 복원되지 않았다.

## 해결
- `4651607`에서 `kd_features/lobby/middleware.ts`를 대폭 개편(약 +426 / -119라인)해 재입장 시 기존 권한·승인 상태를 복원하는 로직을 넣었다.
- `prejoinGuard.ts`, `actions.ts`, `reducer.ts`, `actionTypes.ts`를 함께 조정하고 로비 화면(`AbstractLobbyScreen.tsx`, `LobbyScreen.tsx`) 및 다국어 문구를 보완했다.
- 방장 재입장 정책은 `078e2bf`(docs)로 문서화해 기준을 명문화했다.

## 관련 커밋
- `2026-06-02` `4651607` 브라우저 종료 후 방장 및 참가자 권한 유지
- `2026-06-02` `078e2bf` docs(kd-lobby): 방장 재입장 정책 문서화
