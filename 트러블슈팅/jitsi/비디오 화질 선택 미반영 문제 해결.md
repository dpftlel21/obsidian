# 비디오 화질 선택 미반영 문제 해결

## 문제
사용자가 비디오 화질 옵션을 선택해도 실제 송출 스트림에 즉시 반영되지 않거나, 카메라 재선택 시 설정이 초기화되는 문제가 있었다.

## 원인
화질/해상도 프로필 상태와 실제 비디오 트랙·카메라 설정이 분리되어 동기화 지점이 명확하지 않았다. 선택값이 상태에는 저장되지만 트랙 제약(constraints)까지 전달되지 않았다.

## 해결
- `643ab56`·`c3ed0e0`에서 `kd_features/kd-dashboard/mediaQuality.ts`의 화질 프로필을 실제 트랙 설정에 반영하도록 옵션 처리를 수정했다.
- `26a08c8`에서 `features/base/tracks/middleware.web.ts`, `device-selection/actions.web.ts`, `VideoSettingsContent.tsx`, `VideoDeviceSelection.web.tsx`, `kd-dashboard/functions.ts`·`reducer.ts`를 정리(약 -182라인 정리 포함)해 카메라 변경 시에도 화질 선택이 유지되도록 동기화 경로를 단순화했다.

## 관련 커밋
- `2026-07-30` `643ab56` 비디오 화질 선택 반영 / `c3ed0e0` 비디오 화질 선택 옵션 수정 / `26a08c8` 비디오 카메라 수정
