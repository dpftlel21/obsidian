# 회의 종료 시 싱크 오류 해결

## 문제
회의가 종료되는 시점에 프론트엔드 상태와 서버 세션 상태가 어긋나는 싱크 오류가 발생했다. 종료 처리와 입장 자격 판정이 얽혀 잘못된 상태가 남는 경우가 있었다.

## 원인
회의 세션 종료 시 입장 자격(join eligibility)과 사번(employee number) 기반 식별을 확인하는 로직이 분산되어 있어, 종료 타이밍에 일관된 상태 판정이 되지 않았다.

## 해결
- `05d9952`에서 입장 자격 판정을 `meetingJoinEligibility.ts`로, 사번 처리를 `employeeNumber.ts`로 분리하고 각각 테스트(`.test.mjs`)를 추가했다.
- `meetingSession.ts`를 보정해 세션 상태 갱신을 정리하고, 로비 액션(`features/lobby/actions.any.ts`)과 다국어(`BuiltinLanguages.web.ts`) 처리를 맞췄다.

## 관련 커밋
- `2026-08-04` `05d9952` 회의 종료 시 싱크 오류 수정
