# 고정 컬럼 z-index 충돌

## 🚨 문제 상황
**퇴직금 지급현황 테이블을 태블릿에서 수평 스크롤하면, 고정된 "사번/성명" 컬럼이 "근속(년/월/일)" 그룹 헤더를 완전히 덮어버림**

### 증상
- 근속 헤더 텍스트가 사라져서 어떤 컬럼인지 알 수 없게 됨
- 다른 테이블에서는 발생하지 않는 퇴직금 테이블만의 문제
- 수평 스크롤 시에만 발생 (초기 상태에서는 정상)

## 🔍 원인 분석

### 테이블 구조 (3-level 헤더)
```
┌────────────────────────────────────────────┐
│ 사번 │ 성명 │     퇴직현황                   │   ← Level 1
│      │      ├──────────────────────────────┤
│      │      │ 퇴사유 │ 근속      │ 퇴직연금 │   ← Level 2 (서브그룹)
│      │      │        ├─────────┤         │
│      │      │        │ 년│월│일 │         │   ← Level 3
├──────┼──────┼────────┼───┼──┼──┼─────────┤
│ 0001 │ 홍길동│ 자진  │ 15│ 4│ 0│   DB    │
```

### z-index 계층 구조
- **"사번", "성명"**: `fixed: 'left'` → `position: sticky; left: 0px` + `z-index: 115`
- **"사번", "성명"**: `rowSpan=3` → 3개 헤더 행을 모두 관통하는 큰 셀
- **"근속"**: 비고정 → `z-index: 101` (Level 2 기본값)

### 충돌 메커니즘
1. **수평 스크롤**: "근속" 그룹 헤더가 왼쪽으로 이동
2. **겹침 발생**: "근속"이 고정된 "사번/성명" 위치로 들어감
3. **z-index 우선순위**: 115 > 101이므로 "사번/성명"이 위에 렌더링
4. **텍스트 가려짐**: "근속" 텍스트가 "사번/성명" 배경에 가려져 보이지 않음

### rowSpan의 영향
```tsx
// 고정 컬럼의 rowSpan=3
{ key: 'empNo', title: '사번', fixed: 'left', rowSpan: 3 },
{ key: 'name', title: '성명', fixed: 'left', rowSpan: 3 },
```
- 일반적인 1-level 헤더에서는 rowSpan이 없어 충돌 안 함
- 3-level 헤더에서 rowSpan=3인 고정 컬럼이 모든 레벨을 관통
- Level 2 그룹 헤더와 물리적으로 겹치는 영역 생성

## ✅ 해결 방법 (2단계)

### 1단계: 태블릿에서 고정 컬럼 제거
근본적으로 태블릿에서는 고정 컬럼이 그룹 헤더와 충돌하므로, 모든 고정을 해제:

```tsx
fixedConfig: {
  mobile: {
    left: ['month', 'name'],  // 모바일: 월, 성명만 (그룹헤더 없는 컬럼)
  },
  tablet: {
    // 태블릿: 고정 없음 — 고정 컬럼 rowSpan이 그룹 헤더를 덮는 문제 방지
  },
  desktop: {
    left: ['month', 'empNo', 'name'],
    right: ['total'],
  }
}
```

### 2단계: DataTable z-index 계층 조정
비고정 컬럼의 z-index가 그룹 헤더와 같아서 스크롤 시 덮는 추가 이슈도 수정:

```diff
# shared/ui/composite/data-table/DataTable.tsx

# Level 1: 비고정 ungrouped 컬럼
- zIndex: enableFixedColumns && ... ? 115 : 101
+ zIndex: enableFixedColumns && ... ? 115 : 99

# Level 2: 비고정 그룹 내 컬럼  
- zIndex: enableFixedColumns && ... ? 114 : 100
+ zIndex: enableFixedColumns && ... ? 114 : 98

# Level 3: 비고정 서브그룹 내 컬럼
- zIndex: enableFixedColumns && ... ? 113 : 99
+ zIndex: enableFixedColumns && ... ? 113 : 97
```

### 변경 이유
- **고정 컬럼 z-index(113~115)**: 변경하지 않아 데스크톱에서의 고정 동작은 그대로 유지
- **비고정 컬럼 z-index 감소**: 서로 겹치지 않도록 계층을 명확히 분리
- **공통 컴포넌트 주의**: `DataTable.tsx`는 모든 테이블에 영향하므로 신중히 조정

## ⚠️ 주의사항

### 공통 컴포넌트 영향
- `DataTable.tsx` 수정은 프로젝트의 **모든 테이블**에 영향
- 다른 테이블에서 예상치 못한 z-index 문제 발생 가능성
- 충분한 테스트 필요

### 고정 컬럼 vs 그룹 헤더 충돌 원칙
```
rowSpan이 있는 고정 컬럼 + 그룹 헤더 = 태블릿에서 고정 비활성화
```
- **모바일**: 화면이 좁아 고정이 필수적, 그룹 헤더가 적음
- **태블릿**: 화면이 충분하고 고정과 그룹 헤더 충돌
- **데스크톱**: 화면이 넓어 충돌 가능성 낮음

### 검증 시나리오
1. **데스크톱**: 고정 컬럼 정상 동작, 그룹 헤더 표시 정상
2. **태블릿**: 고정 없음, 그룹 헤더 완전 표시, 스크롤 가능
3. **모바일**: 필수 컬럼만 고정, 충돌 없음

## 💡 예방 전략

### 새 테이블 설계 시 체크리스트
- [ ] 그룹 헤더(2-level 이상)가 있는가?
- [ ] 고정 컬럼에 `rowSpan > 1`이 있는가?
- [ ] 태블릿에서 고정 컬럼이 반드시 필요한가?
- [ ] z-index 계층이 명확히 설계되었는가?

### z-index 계층 설계 원칙
```
고정 컬럼 (113~115) > 비고정 최상위 (99) > 그룹 헤더 (98) > 서브그룹 (97)
```
- 고정과 비고정 사이에 충분한 z-index 갭 확보
- 레벨별로 1씩 감소하여 명확한 계층 구조
- 향후 추가 레벨을 위한 여유 공간 확보

### 고정 컬럼 전략
1. **모바일**: 필수 정보만 최소한으로 고정
2. **태블릿**: 그룹 헤더와 충돌 시 고정 비활성화
3. **데스크톱**: 모든 고정 옵션 활용 가능

## 🔍 디버깅 방법

### z-index 충돌 확인
```css
/* 브라우저 DevTools에서 임시로 배경색 추가 */
.fixed-column { background-color: rgba(255, 0, 0, 0.3); }
.group-header { background-color: rgba(0, 255, 0, 0.3); }
```

### 스크롤 충돌 테스트
1. 브라우저를 태블릿 크기로 조정 (768px~1279px)
2. 테이블을 수평으로 스크롤
3. 그룹 헤더가 고정 컬럼에 가려지는지 확인
4. DevTools Elements 패널에서 z-index 값 확인
