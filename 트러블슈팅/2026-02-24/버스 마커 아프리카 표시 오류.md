# 버스 마커 아프리카 표시 오류

## 📅 발생일
2026-02-24

## 🐛 문제 상황
카카오맵에 서울시 버스 실시간 위치를 표시할 때, 버스 마커가 한국이 아닌 아프리카 대륙(기니만 근처)에 찍히는 현상 발생

## 🔍 원인 분석
### 좌표계 불일치 문제
- **API 응답 데이터**: `posX`, `posY` 필드가 TM좌표계로 반환
  - 예시: `posX: 196212`, `posY: 448218`
- **카카오맵 요구사항**: WGS84 좌표계 (경도/위도)
  - 예시: `lng: 127.027619`, `lat: 37.497952`

### getBusPosByRtid API의 한계
```xml
<itemList>
    <vehId>서울74사2570</vehId>
    <posX>196212</posX>  <!-- TM 좌표계 -->
    <posY>448218</posY>  <!-- TM 좌표계 -->
    <gpsX></gpsX>        <!-- 빈 값 또는 부정확 -->
    <gpsY></gpsY>        <!-- 빈 값 또는 부정확 -->
</itemList>
```

## ✅ 해결 방안
### 2단계 데이터 조회로 해결
1. **1단계**: `getBusPosByRtid`로 버스 목록 확보
2. **2단계**: `getBusPosByVehId`로 개별 차량의 정확한 WGS84 좌표 조회

### 구현 코드
```php
// PHP: curl_multi로 개별 차량 조회
foreach ($handles as $i => $ch) {
    $xml = simplexml_load_string(curl_multi_getcontent($ch));
    $vi = $xml->msgBody->itemList[0];
    
    // WGS84 좌표만 사용
    $buses[$i]['gpsX'] = (string)$vi->gpsX; // 정확한 경도
    $buses[$i]['gpsY'] = (string)$vi->gpsY; // 정확한 위도
}
```

```javascript
// JS: 카카오맵 마커 생성
buses.forEach(bus => {
    if (bus.gpsX && bus.gpsY) { // WGS84 좌표 존재 확인
        let position = new kakao.maps.LatLng(bus.gpsY, bus.gpsX);
        let marker = new kakao.maps.Marker({
            position: position,
            map: map
        });
    }
});
```

## 🎯 결과
- ✅ 버스 마커가 서울시 정확한 위치에 표시됨
- ✅ 실시간 버스 위치 정보의 정확성 확보
- ✅ 사용자가 직관적으로 버스 위치 파악 가능
