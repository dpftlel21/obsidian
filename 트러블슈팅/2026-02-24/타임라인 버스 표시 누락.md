# 타임라인 버스 표시 누락

## 📅 발생일
2026-02-24

## 🐛 문제 상황
정류장 타임라인 모달에서 각 정류장별 버스 개수가 0으로 표시되어 실제 운행중인 버스가 보이지 않는 현상 발생

## 🔍 원인 분석
### API 문서와 실제 응답의 차이
- **API 문서 명세**: `stOrd` (정류소 순번) 필드 포함
- **실제 getBusPosByRtid 응답**: `stOrd` 필드 누락

### 기존 매칭 로직의 한계
```javascript
// 문제가 되는 코드
buses.forEach(bus => {
    // bus.stationSeq가 undefined이므로 매칭 실패
    let matchingStation = stations.find(st => 
        st.seq == bus.stationSeq
    );
    
    if (matchingStation) {
        // 이 조건을 만족하는 버스가 없음
        displayBusAtStation(matchingStation, bus);
    }
});
```

### getBusPosByRtid 응답 예시
```xml
<itemList>
    <vehId>서울74사2570</vehId>
    <plateNo>2570</plateNo>
    <rtNm>472</rtNm>
    <!-- stOrd 필드 누락 -->
</itemList>
```

## ✅ 해결 방안
### 2단계 조회로 정확한 정류소 정보 확보
1. **1단계**: `getBusPosByRtid`로 버스 목록 확보
2. **2단계**: `getBusPosByVehId`로 개별 차량의 정류소 정보 조회

### PHP 구현
```php
// 개별 차량 조회에서 정류소 정보 병합
foreach ($handles as $i => $ch) {
    $xml = simplexml_load_string(curl_multi_getcontent($ch));
    $vi = $xml->msgBody->itemList[0];
    
    // 정확한 정류소 정보 확보
    $buses[$i]['stId'] = (string)$vi->stId;         // 정류소 ID
    $buses[$i]['stationSeq'] = (string)$vi->stOrd;  // 정류소 순번
    $buses[$i]['gpsX'] = (string)$vi->gpsX;
    $buses[$i]['gpsY'] = (string)$vi->gpsY;
}
```

### JavaScript 매칭 로직 개선
```javascript
buses.forEach(bus => {
    // stId와 seq 둘 다로 매칭 시도
    let matchingStation = stations.find(st => 
        st.stId == bus.stId || st.seq == bus.stationSeq
    );
    
    if (matchingStation) {
        displayBusAtStation(matchingStation, bus);
        
        // 정류장별 버스 카운트 업데이트
        let direction = getDirection(matchingStation);
        updateBusCount(direction, matchingStation.seq);
    }
});
```

### 정류장별 버스 표시 함수
```javascript
function displayBusAtStation(station, bus) {
    let direction = station.seq <= turnIndex ? 'up' : 'down';
    let containerId = `${direction}-bus-${station.seq}`;
    let container = document.getElementById(containerId);
    
    if (container) {
        let busElement = createBusElement(bus);
        container.appendChild(busElement);
    }
}
```
