# 하행선 색상 분기 오류

## 📅 발생일
2026-02-24

## 🐛 문제 상황
서울시 일부 버스 노선에서 하행선 폴리라인과 버스 마커 색상이 잘못 표시되는 현상 발생

## 🔍 원인 분석
### transYn 필드 누락 노선 존재
- **일반적인 노선**: 회차점이 있는 정류장에 `transYn: 'Y'` 필드 존재
- **문제 노선**: 회차점 없이 양방향 운행하는 노선에서 `transYn` 필드 자체가 누락
- **결과**: `turnIndex = -1`로 설정되어 상/하행 분기 로직 오작동

### 기존 로직의 문제
```javascript
// 문제가 되는 코드
let turnIndex = stations.findIndex(st => st.transYn === 'Y');
// transYn이 없으면 turnIndex = -1

stations.forEach((st, index) => {
    let pos = new kakao.maps.LatLng(st.gpsY, st.gpsX);
    if (index <= turnIndex) upPath.push(pos);   // -1이면 모든 정류장이 제외
    if (index >= turnIndex) downPath.push(pos); // -1이면 모든 정류장이 하행으로 분류
});
```

### 문제 시나리오
1. `turnIndex = -1` (회차점 없음)
2. 모든 정류장이 `index >= -1` 조건을 만족
3. 전체 노선이 하행(주황색)으로만 표시됨
4. 상행(파란색) 경로가 사라짐

## ✅ 해결 방안
### 회차점 존재 여부 사전 확인
```javascript
let turnIndex = stations.findIndex(st => st.transYn === 'Y');
let hasTurn = (turnIndex !== -1);

// 회차점이 없는 노선 방어 코드
if (!hasTurn) {
    turnIndex = stations.length; // 마지막 인덱스로 설정
}

stations.forEach((st, index) => {
    let pos = new kakao.maps.LatLng(st.gpsY, st.gpsX);
    if (index <= turnIndex) upPath.push(pos);   
    if (index >= turnIndex) downPath.push(pos); 
});

// 폴리라인 렌더링
new kakao.maps.Polyline({ 
    path: upPath, 
    strokeColor: '#3b82f6' 
}).setMap(map);

// 회차점이 있는 경우만 하행선 그리기
if (hasTurn) {
    new kakao.maps.Polyline({ 
        path: downPath, 
        strokeColor: '#f97316' 
    }).setMap(map);
}
```

### 버스 마커 색상 로직도 수정
```javascript
let stIdx = currentStationList.findIndex(s => 
    s.stId == bus.stId || s.seq == bus.stationSeq
);

let busColor = '#3b82f6'; // 기본 상행 (파랑)

// 회차점이 있고, 회차점 이후 정류장인 경우만 하행 색상
if (hasTurn && stIdx > turnIndex) {
    busColor = '#f97316'; // 하행 (주황)
}
```

## 🎯 결과
- ✅ 회차점 없는 노선: 전체 구간이 파란색(상행)으로 일관되게 표시
- ✅ 회차점 있는 노선: 상행(파랑) + 하행(주황) 정상 구분 표시
- ✅ 모든 서울시 버스 노선에서 일관된 색상 표시
