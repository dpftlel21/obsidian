# 증빙자료 결재선 로직 분리 트러블슈팅

## 🚨 문제 상황

**증빙자료가 이미 업로드되어 있을 때 결재선 버튼을 클릭하면 계속해서 "증빙자료를 업로드하세요" 메시지가 뜨는 문제**

### 발생 조건
- 증빙자료는 이미 업로드됨 (img1, img2, file1 등에 값 존재)
- 결재선은 등록되지 않음 (printAppNm, printApp이 null)
- 결재선 버튼 클릭 시 업로드 팝업이 뜸

### 증상
| 상황 | 기존 동작 | 기대 동작 |
|------|----------|-----------|
| 증빙자료 O + 결재선 O | ❌ 업로드 팝업 | ✅ 결재선 팝업 |
| 증빙자료 O + 결재선 X | ❌ 업로드 팝업 | ✅ 결재선 팝업 (신규) |
| 증빙자료 X | ✅ 업로드 팝업 | ✅ 업로드 팝업 |

---

## 🔍 원인 분석

### 문제 코드
```tsx
// VoucherTable.tsx - 기존 hasEvidence 함수
const hasEvidence = (document) => {
  const evidenceFields = [img1, img2, img3, img4, img5, file1, file2, file3, file4, file5];
  
  // ❌ 증빙자료 체크와 결재선 체크가 혼재
  if (!printAppNm || !printApp) return false;  // 결재선 체크
  
  return evidenceFields.some(field => {  // 증빙자료 체크
    const strField = String(field).trim();
    return strField.length > 0 && strField !== 'N' && strField !== 'false';
  });
}
```

### 문제점
1. **관심사 혼재**: 하나의 함수에서 증빙자료와 결재선을 동시에 체크
2. **잘못된 논리**: 증빙자료가 있어도 결재선이 없으면 false 반환
3. **의미 불명확**: 함수명은 `hasEvidence`인데 결재선도 체크

### 로직 플로우 문제
```
결재선 버튼 클릭
    ↓
hasEvidence(item) 체크
    ↓
증빙자료 O, 결재선 X → false 반환
    ↓
❌ 파일 업로드 팝업 실행 (잘못됨)
```

## ✅ 해결 방법

### 1. 관심사 분리
```tsx
// ✅ 증빙자료만 체크 (순수 함수)
const hasEvidence = (document: any): boolean => {
  const evidenceFields = [
    document.img1, document.img2, document.img3, document.img4, document.img5,
    document.file1, document.file2, document.file3, document.file4, document.file5
  ];
  
  return evidenceFields.some(field => {
    const strField = String(field).trim();
    return strField.length > 0 && strField !== 'N' && strField !== 'false';
  });
};

// ✅ 결재선만 체크 (별도 함수)
const hasSignLine = (document: any): boolean => {
  const { printAppNm, printApp } = document;
  return printAppNm && printAppNm !== null && printApp && printApp !== null;
};

// ✅ 결재 가능 여부 (조합 함수)
const isApprovableDocument = (document: any): boolean => {
  return hasEvidence(document) && hasSignLine(document);
};
```

### 2. 결재선 버튼 로직 수정
```tsx
const onSignLineRegister = useCallback((item: any) => {
  // Step 1: 증빙자료부터 확인 (결재선 상관없이)
  if (hasEvidence(item)) {
    // 증빙자료가 있으면 바로 결재선 팝업
    signLineManager.openSignLinePopup(item);
    return;
  }

  // Step 2: 증빙자료가 없는 경우 권한 확인
  if (isWriter(item, empNo)) {
    // 작성자: 업로드 후 결재선 등록
    setPendingSignLineDoc(item);
    openFileUploadForDocument(item);
    showToast('증빙자료를 먼저 업로드해주세요.', 'warning');
  } else {
    // 비작성자: 요청 안내
    showToast('증빙자료가 없습니다. 작성자에게 요청해주세요.', 'warning');
  }
}, [hasEvidence, signLineManager, isWriter, empNo]);
```

### 3. 수정된 로직 플로우
```
결재선 버튼 클릭
    ↓
hasEvidence(item) 체크 (결재선 무관)
    ↓
증빙자료 O → ✅ 결재선 팝업
증빙자료 X → 업로드 팝업
```

## 🧪 테스트 시나리오

### 케이스 1: 증빙자료 O + 결재선 O
```tsx
const testDoc = {
  img1: "image1.jpg",
  printAppNm: "홍길동",
  printApp: "approval_data"
};

hasEvidence(testDoc);        // true (증빙자료 존재)
hasSignLine(testDoc);        // true (결재선 존재)
isApprovableDocument(testDoc); // true (결재 가능)

// 동작: 결재선 팝업 ✅
```

### 케이스 2: 증빙자료 O + 결재선 X
```tsx
const testDoc = {
  img1: "image1.jpg",
  printAppNm: null,
  printApp: null
};

hasEvidence(testDoc);        // true (증빙자료 존재)
hasSignLine(testDoc);        // false (결재선 없음)
isApprovableDocument(testDoc); // false (결재 불가)

// 동작: 결재선 팝업 (신규 등록) ✅
```

### 케이스 3: 증빙자료 X
```tsx
const testDoc = {
  img1: "",
  img2: "N",
  printAppNm: null,
  printApp: null
};

hasEvidence(testDoc);        // false (증빙자료 없음)
hasSignLine(testDoc);        // false (결재선 없음)
isApprovableDocument(testDoc); // false (결재 불가)

// 동작: 업로드 팝업 → 완료 후 결재선 팝업 ✅
```

## 🔧 구현 상세

### 증빙자료 필드 체크 로직
```tsx
const evidenceFields = [
  document.img1, document.img2, document.img3, document.img4, document.img5,
  document.file1, document.file2, document.file3, document.file4, document.file5
];

// 유효한 값 조건
// 1. 문자열 길이 > 0
// 2. 'N'이 아님
// 3. 'false'가 아님
return evidenceFields.some(field => {
  const strField = String(field).trim();
  return strField.length > 0 && strField !== 'N' && strField !== 'false';
});
```

### 결재선 필드 체크 로직
```tsx
// printAppNm: 결재자명
// printApp: 결재선 데이터
const { printAppNm, printApp } = document;

// null이 아니고 빈 값이 아닌 경우 유효
return printAppNm && printAppNm !== null && printApp && printApp !== null;
```

### 수정된 함수들
- `hasEvidence()` - 증빙자료만 체크
