### 📊 시간 순 작업 현황
```dataview
TABLE WITHOUT ID
    choice(completed, "✅ 완료", "⏳ 대기") as "상태",
    regexreplace(text, ".*\[(.*?)\].*", "$1") as "작업명",
    regexreplace(text, ".*⏰ (\d{2}:\d{2}).*", "$1") as "시간"
FROM ""
WHERE file.path = this.file.path AND contains(text, "#daily") AND contains(text, "⏰")
SORT regexreplace(text, ".*⏰ (\d{2}:\d{2}).*", "$1") ASC
```

## 🚀 프로젝트 연결 & 추적

### 💼 Projects 폴더 연동
```dataview
TABLE WITHOUT ID
    "📊" as "아이콘",
    file.link as "프로젝트명",
    choice(progress, progress + "%", "미설정") as "진행률",
    choice(status, status, "진행중") as "상태",
    choice(priority, priority, "일반") as "우선순위"
FROM "Projects"
WHERE file.name != "README"
SORT choice(priority = "긴급", 1, choice(priority = "중요", 2, 3)) ASC
```
