## 🚨 트러블슈팅 (React Hook 규칙 위반)

### 문제 상황
- loadingStore.ts의 loadingSelectors 객체에서 Hook 호출 문제
- "React Hook "useLoadingStore" is called in function "globalLoading" that is neither a React function component nor a custom React Hook"

### 해결 과정
1. **문제 분석**: 일반 객체 메서드에서 Hook 호출 시 규칙 위반
2. **사용처 확인**: grep으로 검색 → 다른 파일에서 미사용 확인
3. **해결책 적용**: 
   - 사용되지 않는 selectors 제거
   - useComponentLoading에서 직접 state 접근으로 변경

```typescript
// 수정 전 (문제 코드)
export const loadingSelectors = {
  globalLoading: () => useLoadingStore((state) => state.globalLoading), // Hook 규칙 위반
}

// 수정 후 (해결된 코드)
export const useComponentLoading = (key: string) => useLoadingStore((state) => ({
  loading: state.loadingStates[key] || false, // 직접 접근으로 변경
  setLoading: (loading: boolean) => state.setComponentLoading(key, loading),
}));
```
