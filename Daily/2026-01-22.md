## 🚀 프로젝트 연결 & 추적

### 💼 Projects 폴더 연동
```dataview
TABLE WITHOUT ID
    "📊" as "아이콘",
    file.link as "프로젝트명",
    choice(progress, progress + "%", "미설정") as "진행률",
    choice(status, status, "진행중") as "상태",
    choice(priority, priority, "일반") as "우선순위"
FROM "Projects"
WHERE file.name != "README"
SORT choice(priority = "긴급", 1, choice(priority = "중요", 2, 3)) ASC
```
