### 🤖 Full Calendar 이벤트 자동 로딩
```dataview
TABLE WITHOUT ID
    choice(contains(string(file), "event"), "📅 " + file.link, "📋 " + file.link) as "이벤트/작업",
    choice(contains(string(file), "2026-01-21"), "✅ 오늘", "📅 다른날") as "날짜"
FROM ""
WHERE contains(string(file), "2026-01-21") 
   OR contains(fc-date, "2026-01-21")
   OR date(file.day) = date("2026-01-21")
SORT file.ctime DESC
```

### 📊 오늘 작업 통계
```dataview
TABLE 
    length(filter(file.tasks, (t) => !t.completed)) as "미완료",
    length(filter(file.tasks, (t) => t.completed)) as "완료",
    round(length(filter(file.tasks, (t) => t.completed)) / length(file.tasks) * 100, 1) + "%" as "완료율"
FROM ""
WHERE file.name = this.file.name
```
