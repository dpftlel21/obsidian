## 🚨 트러블슈팅 (좌표계 불일치)

### 문제 상황
- 카카오맵에 버스 마커가 아프리카 대륙에 표시되는 현상
- "getBusPosByRtid API의 posX, posY가 TM좌표계로 반환"

### 해결 과정
1. **문제 분석**: TM좌표계 vs WGS84 좌표계 불일치 확인
2. **원인 파악**: API 문서와 실제 응답 데이터 차이 발견
3. **해결책 적용**: 
   - 개별 차량 조회(getBusPosByVehId)로 WGS84 좌표 확보
   - gpsX, gpsY 필드만 사용하도록 로직 수정

```php
// 수정 전 (문제 코드)
$buses[$i]['posX'] = (string)$vi->posX; // TM 좌표계

// 수정 후 (해결된 코드)  
$buses[$i]['gpsX'] = (string)$vi->gpsX; // WGS84 좌표계
$buses[$i]['gpsY'] = (string)$vi->gpsY; // WGS84 좌표계
```

## 🚨 트러블슈팅 (배열/객체 파싱 오류)

### 문제 상황
- 경기도 버스 1대 운행 노선에서 "forEach is not a function" 에러 발생
- XML 파싱 시 단일 요소는 객체, 다중 요소는 배열로 반환되는 차이

### 해결 과정
1. **문제 분석**: simplexml_load_string의 파싱 동작 차이 확인
2. **방어 로직 구현**: 
   ```php
   // PHP 배열 정규화
   if (!isset($items[0])) {
       $items = [$items];
   }
   ```
   ```javascript
   // JS 배열 확인
   if (!Array.isArray(buses)) {
       buses = [buses];
   }
   ```
