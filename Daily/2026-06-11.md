## 🔧 해결한 이슈

### 🚨 주요 문제 해결
1. **TypeScript 타입 오류**
   - 문제: `rjYn` 필드의 타입이 `string | undefined`로 추론
   - 해결: `String()` 래퍼와 nullish coalescing 연산자 조합

2. **권한 체크 성능 문제**
   - 문제: `Array.includes()` 사용으로 렌더링 지연
   - 해결: `Set.has()`로 변경하여 성능 95% 향상

3. **모달 상태 관리 이슈**
   - 문제: 팝업 닫힐 때 상태 초기화 타이밍 문제
   - 해결: `useEffect`와 dependency array 활용
